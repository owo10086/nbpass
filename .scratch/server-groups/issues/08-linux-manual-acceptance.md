**What to build:** 在真实 Linux 面板、真实节点和测试 DNSPod 域名上，按票 01–07 完成人工验收，并把结果追加到各票 Comments。测试域名所在套餐需支持至少 3 条同名同线路 A 记录同时启用；另准备一个只支持 2 条的场景验证超限提示（没有条件时注明未验）。

**Blocked by:** 01, 02, 03, 04, 05, 06, 07

**Status:** ready-for-human

**Refs:** 规格全部用户故事

- [ ] 从 v1 版本升级后，已有主备组发布、切换、回切照常
- [ ] 单节点规则：直连与隧道各一条，客户端连节点地址和绑定域名都能通，流量统计正常
- [ ] 全部发布组：3 个成员绑定记录后首次发布，`dig` 能看到 3 个地址
- [ ] 停掉一个成员，确认被摘除；恢复后 1 分钟以上加回
- [ ] 制造被墙（或模拟自测异常），确认摘除 → 换 IP → 记录改为新地址且仍暂停 → 复检通过后加回
- [ ] 观测模式下重复上述故障，确认 DNS 与 IP 都不变，只有事件和 Telegram 通知；手动摘除仍生效
- [ ] 最少保留数为 1 时停掉全部成员，确认保留一条并收到通知
