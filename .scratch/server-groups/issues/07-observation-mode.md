# 07: 入口组观测模式

**What to build:** 入口组增加观测模式开关，新建组默认关闭，主备和全部发布都可用。开启期间该组的所有自动动作（入口切换、回切、摘除、加回、偏差写回、因该组申请的换 IP）只记录"本来会做什么"并发 Telegram，不提交协调器、不改期望版本、不占换 IP 额度。所有自动动作在提交、以及调用外部接口前的最后一步都复核观测状态。开启开关时：尚未调用外部接口的自动 DNS 动作作废并记事件；尚未下发给节点的自动换 IP 许可作废并释放额度；已经下发的许可不撤回（节点没有撤回能力，本票不改节点协议），按可能已执行继续核对；已经调用外部接口的动作照常核对结果，不当作取消成功。开启前已下发或已执行的自动换 IP，确认新地址后的地址同步属于原动作收尾，照常执行并保持各记录原启用状态；该收尾不触发切换、摘除、加回或偏差写回。节点所属的任一入口组开着观测模式，该节点就不自动换 IP，即使申请来自出口用途或单节点入口用途。手动操作（手动切换、手动摘除与加回、首次发布、手动换 IP、手动同步地址）及其后续 DNS 更新不受限制。关闭后按当时状态重新判断，不重放观测期间记录的动作。入口组页醒目显示观测中，并列出最近的"本来会做的动作"。

**Blocked by:** 03, 06

**Status:** ready-for-agent

**Refs:** 规格用户故事 16、17；GLOSSARY「观测模式」；`entry_coordinator.go`、`entry_dns_audit.go`、`cross_group_rotation.go`、`rotation.go`

- [ ] 观测中的主备组：活动入口离线确认后只记录"本来会切到 X"并通知，记录不变；回切同理
- [ ] 观测中的全部发布组：成员被墙后只记录"本来会摘除"，记录不变；加回同理
- [ ] 观测中的组发现记录偏差时只记录，不写回
- [ ] 节点同属观测组和非观测组：被墙时不换 IP，非观测组的切换或摘除照常执行
- [ ] 节点同属观测组且是开了被墙处理的出口，或承载单节点规则：仍不自动换 IP
- [ ] 不属于任何观测组的单节点入口被墙时照常换 IP
- [ ] 开启开关与动作提交或换 IP 许可下发竞争：未调用外部接口的 DNS 动作与未下发的许可被作废并释放额度；已下发的许可按可能已执行核对；重启后不续跑被作废的动作
- [ ] 商家接口已调用、尚未确认新地址时开启观测：确认新地址后记录地址照常同步、启用状态不变，不发生摘除、加回或切换
- [ ] 观测期间手动切换、手动摘除、手动换 IP 及其后续记录更新照常生效
- [ ] 关闭观测模式后按当前状态判断并执行，不重放历史记录
- [ ] 以上行为由测试台通过面板 HTTP API、假 DNSPod 与假换 IP 接口验证
