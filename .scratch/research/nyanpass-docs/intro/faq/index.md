# FAQ

这是面板的常见问题，节点的 FAQ 请看[这里](../../reference/nc-wtf/index.md)。

<a id="_1"></a>
## 我没有使用转发面板的基础，推荐购买吗

不推荐。如果您实在要买，请确保您有一个“技术”人员。

<a id="403"></a>
## 搭建完成后，访问显示 403

可能是因为您的授权域名不匹配，请从已授权的域名访问。

<a id="_2"></a>
## 搭建完成后，访问显示空白

请检查您的反代是否正常。

1. 访问 <https://您的域名/api/v1/> 应该返回 JSON 数据
2. 访问 <https://您的域名/> 应该返回前端网页

<a id="502"></a>
## 访问显示 502 或者显示“请求出错”提示框

“请求出错”很有可能是 `/api/` 的反代有问题导致的，具体错误请看浏览器 Dev Tools 中的报错。如果请求 `/api/*` 均返回 502 错误，那么很有可能是面板后端未启动。

<a id="_3"></a>
### 面板未启动的常见原因

1. 授权到期
2. 面板服务器时间未同步
3. 面板版本过旧
4. 站点端口被其他程序占用

具体请查看面板端日志。

<a id="ip"></a>
## 可以用纯 IP 或者非标准端口搭建吗？

不可以，即使您搭建了，节点端也无法正常对接。

<a id="http"></a>
## 可以 HTTP 吗？

不可以，为了安全必须配置 HTTPS。

<a id="_4"></a>
## 授权域名被墙怎么办？

被墙后处理：

1. 国内入口直接挂代理对接，无视墙。
2. 更换授权域名，具体流程请进入工单系统查看步骤。

> **推荐使用怎样的域名**
>
> 1. 由于面板域名一般可以长期使用，并且更换比较麻烦，涉及节点机器失效和重新配置。因此推荐使用 `com` `org` 等可长期续费的域名，**避免使用第一年低价后续高价的域名**。
> 2. 目前大多数域名被墙案例都是因为**一级域名下的其他子域名放了一些不好的东西，被 GFW 发现后封禁了整个域名**。因此推荐您的授权域名单独使用，不要同时放其他东西，这样就不会被墙。

<a id="_5"></a>
## 安全提示

以下内容请妥善保管，泄漏造成的一切后果自负。

- 管理员帐号与密码（尽量用随机密码，否则可能被人猜到）
- 授权码
- 数据库文件或密码

<a id="_6"></a>
## 支付对接失败

检查各项参数，特别是 API URL 是否填写完整，不能只填写域名。

例如 Epay `https://xxx.com` 这样写是不正确的。正确写法是 `https://xxx.com/submit.php` 而且有些商家接口可能不是 submit.php，要看具体情况。

<a id="cpu"></a>
## 面板端消耗大量 CPU 或内存

- 设备不要挂太多（包含用户单端设备）
- 用户数量不要太多

<a id="0"></a>
## 用户已用流量一直是 0

检查设备组设置，是否倍率为 0。

<a id="_7"></a>
## 如何找回授权码

如果您的面板机器仍能通过 ssh 连接上，或者有备份，那么直接查看 `config.yml` 获取授权码。

其他情况，请进入工单系统查看步骤。

<a id="udp"></a>
## 转发 UDP 的问题

除非有明确且无法替代的需求，否则不建议折腾 UDP/QUIC 转发。

目前 UDP L4 转发在传递客户端真实 IP 等方面存在较多限制，配置、兼容性和排障成本也比较高，实际使用中容易遇到各种问题。

尤其是 QUIC，它本来就适合直接运行在最靠近用户的边缘节点上。额外增加转发不仅会带来难以传递真实 IP 的麻烦，还可能明显影响性能，通常得不偿失。
