# 对接节点端

<a id="_2"></a>
## 安装

<a id="_3"></a>
### 系统兼容性

支持的系统： Debian(11+) Ubuntu(22.04+)

支持的架构：`amd64` `amd64v3` `arm64`

**其他系统或架构默认不支持，强行安装后果自负。**

非 root 环境：理论上可以手工运行，不支持一键安装。可能有小部分功能无法使用。

<a id="_4"></a>
### 在线安装

在设备组界面点击 `对接 - 复制在线安装命令` 然后在对应机器运行。

如需多台机器负载均衡，请运行同一条对接命令。

有时（主要是中国机器），您可能遇到无法在线安装（没有进入下载阶段，或者下载卡住，或者下载失败），大概率是网络问题，这种情况下**推荐使用离线部署功能**。

> **复制在线安装命令时，我应该选择 “自动探测线路”还是“海外主线路”？**
>
> 在 nyanpass 最新版本中，在线安装命令分成两种。
>
> “自动探测线路”在国内机器的安装成功率较高。但是无法在 AWS EC2 等海外月抛机器上安装。
>
> “海外主线路”针对海外机器网络优化，稳定性高，安装成功率高。在国内机器的安装成功率较低。对于那些月抛自动开机的，请务必使用海外线路，不要使用自动探测。

> **安装脚本环境变量**
>
> 示例： `S=nyanpass bash < ......`
>
> 1. `S` 用于指定安装名。若指定，则进行无交互安装，同时可以使用下面的环境变量。
> 2. `OPTIMIZE=1` 优化系统参数。
> 3. `INSTALL_TOOLS=1` 安装常用工具。

<a id="_5"></a>
### 离线部署

在设备组界面点击 `对接 - 离线部署` ，按照提示操作。

> **提示**
>
> 离线部署的原理是让你通过其他途径（主要是 SFTP）把安装包传到机器上面。既然你的机器已经由于网络问题无法在线部署，就不要再尝试在这台机器上下载了。

<a id="_6"></a>
### 出口端如何指定端口 / 连接地址

默认情况下，出口端的连接地址采用公网 IPv4，端口为随机生成。

如需指定端口 / 连接地址，请[修改对接命令](../../reference/nc-command/index.md)。

如需使用 IPv6 连接出口端，请在入口指定[ipv6\_group](../../reference/connect/index.md)
