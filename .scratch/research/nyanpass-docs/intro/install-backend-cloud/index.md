# 云托管面板

> SaaS（软件即服务）是一种基于云的软件交付模式，用户通过互联网按需订阅使用软件，而无需在本地安装或维护。 SaaS 提供商负责软件的托管、维护和更新，用户通过Web浏览器等方式访问，是云计算的三种主要服务模型之一。

> **需要注意**
>
> 1. 请勿不按文档乱来。不懂请问 AI，再不懂请找人代搭。
> 2. 托管面板服务器为共享，无在线时长和访问速度保证。
> 3. 托管需要额外支付初装费，初装费不可退款。

<a id="1"></a>
## 1 获取后端地址

官方处理完毕后，您将获得一个 **CNAME 路由地址** (例如 `ny.example.com.saas.xxxxxx.com`)。请将这个地址绑定到 Cloudflare（一般用户推荐用这个），同时也支持其他允许 Websocket 和 IPv6 回源的 CDN。

<a id="_2"></a>
### 💡 工作原理说明 (重要)

本服务采用 **CNAME 接入方式**。

您提供的 CNAME 地址（例如 `ny.example.com.saas.xxxxxx.com`）是一个“后端路由地址”，它的作用是像桥梁一样，把您的域名流量引导至我们的服务器。

> **⚠️ 注意：**
>
> 1. **不要直接访问该 CNAME 地址**：它没有配置独立证书，直接访问会提示“连接不安全”或无法访问。
> 2. **不要通过 Ping 测试**：该地址仅用于解析路由，并非普通的 Web 服务器，Ping 不通属于正常现象。

<a id="2-cloudflare"></a>
## 2 Cloudflare 设置 (关键步骤)

请在您的域名解析商（Cloudflare）中添加一条记录。**请务必严格按照以下参数设置，否则会导致页面无法打开。**

| 记录类型 | 名称 (Name) | 目标 (Target) | 代理状态 (Proxy) |
| --- | --- | --- | --- |
| **CNAME** | `ny.example.com` | `ny.example.com.saas.xxxxxx.com` | **必须开启 (小黄云)** |

为了确保 HTTPS 正常工作，请在 Cloudflare 面板进行以下调整：

1. **SSL/TLS 设置**：请将加密模式设置为 **"完全 (Full)"**。
2. *注：请勿选择“严格 (Strict)/灵活 (Flexible)”，否则会报 5xx 错误或者循环重定向。*
3. **WebSocket**：请确保已**启用**（默认开启）。

<a id="3"></a>
## 3 访问服务

配置完成后，您直接访问**您自己的域名**（例如 `https://ny.example.com`）即可进入管理面板。

<a id="_3"></a>
## 服务器

托管面板服务器为共享，不接受任何导致高占用（如 DDCC 攻击、用户和设备很多的大转发站）的情况。若发现，立即清退该用户，不得再托管。

如果您持续受到 CC 攻击，可以联系作者付费定制 CC 缓解服务。
