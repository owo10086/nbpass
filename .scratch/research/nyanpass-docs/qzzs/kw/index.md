# 国内跨网问题

> 转载自 <https://t.me/wtfbugtoday/1003>

从去年（2024）年初三家运营商开始施行跨省结算以后，各方面的流量（包括但不限于PCDN）作为应对选择了跨网调度的方式来解决（例如给电信用户调度联通的pcdn节点，因为目前三家运营商之间的互联是没有结算费用的），进而导致过去一年多时间里面跨网流量越发拥塞，现在某些省份已经到了白天都会大爆炸的地步了（比如广东移动到广东电信白天都能丢上30%甚至50%，再比如广东联通到电信中午12点过后延迟从10多ms飙涨至60多ms）

众所周知省内结算的原因就是为了避免某些省份恶性竞争拉低CDN流量单价导致的利润损失和部分省份吃不到业务没利润的情况，归根结底还是钱的问题，现在三家运营商之间拥塞的情况明显运营商是没有动力去扩容的，因为本身就是为了让流量在本网内，你跨网丢包正好用户也不好受，你来买我带宽，我才能赚钱，你全用隔壁家透传到我这里了我还赚个叼毛。

这东西带来的影响就是，所有涉及跨网的流量都可能爆炸，比如香港CMI三网回程的，到电信就可能会因为跨网拥塞导致低速，至于9929到163和CN2回联通稍微好一点是因为彼此精品网和普通网有互联（163-9929/4837-4809，但是容量并不大），但是电联到CMIN2是必须要过9808的，因此就算你买的是N2，到了跨网这里该炸还是得炸

始终记住：没有任何一个方案一定是永久好用的，完全取决于整个网络路径上拥塞在哪里，早几年只有跨境段拥塞的时候，借跨境段不拥塞的运营商再跨网回程确实是很好的选择，但是现在跨网都已经炸得稀烂了，只能看跨境和跨网哪一段更好一点再做选择了。

当前建议的解决方案：用本网直连或优化的线路会是更好的选择（比如电信用自家CN2，联通普通4837直连或者9929，移动用N2）

> **总结**
>
> 某三家运营商不做人，用户想解决跨网问题除了加钱别无他法（当然也可以摆烂不解决）。
