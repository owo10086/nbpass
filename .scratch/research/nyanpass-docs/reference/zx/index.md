# 专线怎么对接

市面上的专线通常分为以下类型：

<a id="_2"></a>
### 单机专线

专线出口端直接对接为「入口」，选择 `直接转发 / 入口直出策略` 为 `可选` 或 `强制`

如果专线出口直接连接转发目标出现网络问题，在 `直接转发 / 入口直出策略` 为 `可选` 模式下，可以自己外接出口跳板，解决直连目标不通的问题。

<a id="_3"></a>
### 双机专线

双机专线由入口机和出口机组成，提供两种对接方式：

<a id="ip"></a>
#### 简单对接（无法传递用户 IP）

- 入口机器通过 `iptables` / `nftables` 将端口转发到出口机器
- 仅出口机对接面板，使用上述 单机专线 的方式对接

<a id="ip_1"></a>
#### 复杂对接（可以传递用户 IP）

- 入口机对接为「入口」，出口机对接为「出口」
- 出口机器安装时需指定 `--connect-host 内网IP` 参数，使其连接回入口机的内网地址

<a id="ix"></a>
### IX 专线

IX 专线的架构与双机专线类似：

| 角色 | IX 专线称呼 | 双机专线称呼 |
| --- | --- | --- |
| 入口机 | 前置机 | 入口机 |
| 出口机 | IX 机 | 出口机 |

> **注意**：若在入口机（国内云厂前置机）上安装节点端，可能引发某些问题。因此目前不推荐使用 IX 专线。
