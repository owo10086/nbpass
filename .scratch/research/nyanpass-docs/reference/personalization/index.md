<a id="_4"></a>
## 付费定制功能

**一般来说，不接受直接在 ny 面板上定制功能。** 在面板之外的定制，视预算可以考虑。

目前有以下公开的定制功能：

<a id="whmcs"></a>
### WHMCS

> 购买此定制功能的前提是已经购买 Lv2 授权。

与 WHMCS 整合，可以实现使用 WHMCS 管理用户和财务，nyanpass 只作为管理转发使用。

交付形式：整合套件的源码，指导初次部署。

<a id="_5"></a>
### 邀请注册

> 购买此定制功能的前提是已经购买 Lv2 授权。

简易的邀请注册、邀请返利。

交付形式：开启邀请注册功能权限，允许一个授权 key 在其有效期内使用（续费无须额外支付费用，但是不可转移权限）。
