# 服务器状态

服务器状态，又称探针，是参考 nezha-agent 客户端定制的一套系统，用于方便管理节点端。

现在的探针均指 `节点状态 (新)`，旧探针已不再维护，不会有任何新功能添加。

<a id="_2"></a>
## 正确的使用方式

从面板主界面打开。

一些数据（用户信息、最新节点端版本等）是由面板主界面传递给探针的，如果您直接打开探针，可能会出现问题。

如果需要刷新这些数据，请先刷新主界面，再打开探针页。

<a id="_3"></a>
## 关于统计数字

我们对默认未设置 `COUNT_INTERFACE` 的情况定义为“智能统计”，此时探针中的带宽、流量统计数字，一般表示可以服务器的公网流量消耗。

但是有一些情况下，这些数据与公网流量消耗并不相等，因为“智能”选择网卡不够智能。特别是服务器有多个网卡、使用 br slave 网卡等情况。您可以使用 `COUNT_INTERFACE` 手动选择统计网卡。

所以，在您完全搞清楚这些数据的统计口径、单位换算之前，您不应该依赖这些数字，也不应该将数字与任何其他地方的数字比较（别的软件有别的统计方法）。

<a id="_4"></a>
## 关于权限

考虑到很多用户需要方便，软件默认开启了 WebSSH，但是这样做会有一些安全问题，例如别人知道面板管理员密码后可以到节点机器执行任意命令。

如果你不需要 WebSSH，可以设置 [`DISABLE_EXECUTE`](../nc-environment/index.md) 环境变量关闭此功能。
