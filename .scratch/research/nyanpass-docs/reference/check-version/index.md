# 检查版本

<a id="_2"></a>
## 面板端

方法一: 登录后在“主页”查看“后端信息”

方法二: 运行 `./rel_backend -h`

<a id="_3"></a>
## 节点端

方法一: 在“服务器状态”页面，鼠标置于“状态”上，有悬浮提示。

方法二: 运行 `/opt/nyanpas/rel_nodeclient -h`

<a id="_4"></a>
### 如何升级入口/出口节点的版本

方法1:

先刷新主页面，然后再进入或刷新服务器状态页面。（建议用 Ctrl+F5 刷新）

这时你应该可以看见“服务器状态”中有升级提示，按照提示下发升级指令就可以了。

方法2:

如果方法1不可用，那么你可以ssh到“需要升级的节点机器”上，再次运行对接脚本，输入“需要升级的服务名”。然后选择 `u` 保留配置重装程序，即可实现升级。
