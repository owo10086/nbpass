# 设备组设置

<a id="_2"></a>
## 分组与负载均衡

对于“入口”设备组：多台机器对接在同一设备组内，代表这些机器共用一套入口规则。面板无法控制用户到入口的流量，因此入口组不自带负载均衡效果。

对于“出口”设备组：多台机器对接在同一设备组内，代表这些机器共用一套出口规则。每台入口服务器连接这个出口组时，会以“最小连接数”的方式均衡出口组内各机器的负载，同时默认启用故障转移与健康检查。

<a id="_3"></a>
## "限制出口" 的写法

- `禁止单端` = 禁止使用单端，但允许使用站点的出口
- `1,2,3` = 只允许使用1,2,3出口，但不禁止单端
- `1,2,3,禁止单端` = 禁止使用单端，且只允许使用1,2,3出口
- `1145141919` = 若这个设备组 ID 不存在，则代表只允许使用单端

<a id="_4"></a>
## 出口故障转移组

适用情景举例：短期内无人值守，有 Aws HK #1 (月抛，速度快) 与 HKT #2 (正价，速度一般) 两组服务器，为避免 AWS 全挂导致规则全挂的情况，可以设置 AWS 的故障转移组为 #2 HKT。

- 当出口组的所有机器均判定为故障，则后续隧道连接直接分配至故障转移组。
- 判定的依据主要是 TCP 握手超时或 refused，一些奇怪的问题可能无法判定为故障。判定过程可能需要长达数秒的时间。
- 故障转移组需要允许相同的用户组使用，否则可能出现未定义的行为。
