# 沪日美专线组网

把 IX、日美内网映射与落地端点组织成可验证的多层路径。

本例组织一条 `上海入口 → 沪日 IX → 日美内网 → 美国出口`路径。商家是否提供内网、可用地址和带宽需要按实际线路确认；面板不会替你开通这些网络条件。

## 先分清映射与面板逻辑

| 地址 / 端口 | 用途 |
| --- | --- |
| 美国端点绑定地址与端口 | forwarder 在美国机器上实际监听 |
| 日本入口的映射端口 | 接收前一跳连接，再经商家内网送往美国端点 |
| 面板端点的对外地址与服务端口 | 告诉前一跳如何通过日本映射连接美国端点 |

下面的端口只是示例，保存时使用自己的实际分配值。

## 第一步：部署美国端点

在 **转发端点**创建美国 forwarder，填写有效地址，设置或记录本机绑定端口，例如 `48350`，按该记录部署并验证监听。

![对外服务端口与本机绑定端口分别配置](https://img.coderluny.com:444/uploads/zfc-tutorial-20261018-endpoint-basic-277ef4dcc27c.png)

不要随意填写一个地址后就当作部署完成。先确认日本机器能通过商家内网访问美国绑定地址和端口。

## 第二步：建立日本到美国的内网映射

在日本机器上部署入口 worker，添加普通端口转发：

- 线路：日本 worker。
- 目标：美国端点的商家内网地址与绑定端口，例如 `10.20.0.2:48350`。
- 日本服务端口：例如 `31784`，或使用保存后实际分配的端口。
- 监听协议：与承载的端点传输匹配，分别验证 TCP / UDP。

![普通端口转发的线路、目标与服务端口](https://img.coderluny.com:444/uploads/zfc-tutorial-20261018-port-basic-33afbae1bbab.png)

确认日本的 `31784` 确实能到美国 forwarder，再进行下一步；不要把此规则的目标又指回日本同一监听端口。

## 第三步：公布前一跳应连接的地址

将美国端点记录的 **对外 IP / 域名**指向前一跳可访问的日本地址，**服务端口**设为日本映射的 `31784`；美国本机的 **绑定 IP / 端口**仍保持实际监听配置。

```text
前一跳 → 日本可达地址:31784 → 商家内网 → 美国绑定地址:48350
```

这条面板端点记录代表美国服务，只是通过日本映射接入。地址转换不等于在日本额外运行一份相同身份的 forwarder。

## 第四步：组织候选组和链

多条日美内网映射可以分别准备后放入同一 **端点组**，表示这层的不同候选。若两家商家的内网彼此不可达，不要拆成可任意交叉组合的日本组和美国组；可分别封装为完整映射候选。

![端点组的成员与候选顺序](https://img.coderluny.com:444/uploads/zfc-tutorial-20261018-endpoint-group-5019d01db2e6.png)

在上海入口的端口中选 **链式转发**，按 `沪日 IX 组 → 日美映射候选组`排列。映射候选已经连接到美国端点，不需要把同一个美国服务再重复加成下一层。

![链式路径、智能选择和固定前后跳数](https://img.coderluny.com:444/uploads/zfc-tutorial-20261018-port-chain-316e0f9fa2d4.png)

必须保留 IX 或内网时，设置固定前 / 后跳数，或关闭智能选择。开启智能选择并不保证所有指定层都经过。

## 第五步：按需提供入站代理

若要给客户端提供 SS、VLESS 等代理入口，展开 **入站配置 → 启用入站代理**，用表单选择协议和认证参数。

![入站代理配置表单](https://img.coderluny.com:444/uploads/zfc-tutorial-20261018-inbound-ss-e696b23951e1.png)

不需要手写 `{"Ss":{}}`。没有额外出口代理时，真实访问目标由客户端携带，探测地址只用于连通性检查。完整参数见[入站代理](../inbound-proxy/index.md)。

## 第六步：逐段验证并演练备用

1. 日本直接访问美国内网绑定端口。
2. IX 端访问日本映射端口。
3. 上海入口经完整链访问真实目标。
4. 核对实际出口与每段流量、带宽和丢包。
5. 在测试线路验证某个候选故障、整层故障和恢复。

TCP Ping、ICMP 与真实业务测量的是不同对象，不能笼统认定某种探测必然比应用延迟更低。单一入口、单一 IX、共享商家上游仍可能是故障点；需要另一套完整路径时配置 [Fallback](../multi-fallback-line/index.md)。
