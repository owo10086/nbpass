# 可视化网络规划

在端口拓扑图中查看路径与测量，编辑节点、边和 TOT 子流，校验后保存并核对实际连接。

端口的基础路径先按[转发指南](../fwd-guide/index.md)或[动态多级转发链](../fwd-chain/index.md)配置，再进入 **端口管理 → 该端口的更多操作 → 网络规划**，对这个端口精细规划。

## 先读图，再修改

![端口网络规划图与图例](https://img.coderluny.com:444/uploads/zfc-tutorial-20261018-network-planning-6a0c05b300d9.png)

顶部显示当前传输类型、入站代理标记、智能选择和固定前／后跳数。组线路可选择具体入口 worker，先确认正在观察哪一个入口。

**刷新延迟／失败率**用于重新获取测量信息；需要相应读取权限。测量与拓扑应结合时间看：缺失的指标不表示延迟为零，画出一条边也不证明实际业务已经经过它。

**图例**说明颜色与交互：绿色实线表示选中／新增边，灰色虚线表示禁用边，数字表示相应权重。先使用搜索和边过滤减少干扰；视觉过滤不会删除实际配置。

## 不同模式可以改什么

| 模式 | 重点 |
| --- | --- |
| 直连 | 只供查看，不支持网络规划编辑 |
| Hammer 单跳 | 核对该层候选和界面开放的节点／权重设置，不能添加链式跨层边 |
| 转发链 | 可编辑符合约束的节点、边、优先级与跨层边 |
| TOT | 使用专用子流配置和落地优先级，不能照搬普通链式规划操作 |

入站代理没有固定落地目标时，图中会明确提示；真实目标由客户端请求决定，不能用某个探测地址代表所有请求的拓扑。

## 调整节点与边

1. 单击节点查看其信息和可编辑项。
2. 再选择另一个节点，编辑二者之间的边；也可直接点击边或权重数字。
3. 需要新增跨层连线时使用 **添加跨层边**，确认方向与必经层约束。
4. 检查禁用节点／边后是否仍有完整可达路径，避免把一整层候选全部排除。
5. 对支持的节点使用定时禁用时，核对恢复时间和时区。

**延迟偏移**作为选路偏置，越小越优，在按延迟选路的策略中才有意义；它不是实际测出的物理延迟。**选择权重**只在静态加权轮询下生效，数值越大分配机会越多。它不保证实际吞吐量严格按比例，不能与毫秒偏移混填。

图例列出的快捷键仅在选中边／节点对、且当前模式支持时使用。删除“新增边”、禁用已有边和删除节点不是同一操作；操作后检查顶部的未保存变更摘要。

## TOT 子流配置

TOT 图提供子流方向、带宽、权重、延迟阈值、原生 UDP、活跃时间窗和子连接数等受管字段，实际可见项以当前子流为准。先确认汇聚点和子流角色，再调整，详细含义见[单线程带宽聚合](../bw-merge/index.md)。

时间窗按界面提示填写并检查本地时间。TOT 的落地优先级与子流配置分步保存，不能把部分保存成功当作全部设置已经提交。

## 校验、保存与冲突处理

- **校验**检查规划约束，不执行真实业务验收，也不等于保存。
- **撤销／重做**用于本地规划编辑；**重置规划**前先确认要放弃哪些未保存变化。
- **保存**可能分步提交规划和节点／子流配置；出现错误或仍显示未保存时，逐项核对，不立即宣称所有变更都已回滚或全部生效。
- 如果端口被其他操作改过，服务端可能返回配置冲突。重新读取最新配置并比较后再编辑，不反复提交旧快照覆盖别人修改。

保存后检查端口同步，再用新建连接验证预期路径、必经层、故障回退和恢复。原有长连接不会因为改图就保证无缝迁移；真实连接与拦截情况见[诊断与测速](../diagnostics-speed-test/index.md)。
