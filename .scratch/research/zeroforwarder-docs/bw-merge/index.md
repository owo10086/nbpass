# 单线程带宽聚合

在 TOT 聚合表单中配置汇聚服务器、多端点或链式子流，并验证单连接吞吐。

TOT 聚合通过多条子流承载同一个连接，在汇聚服务器重新汇合。它与“从多个候选里选一个出口”的负载均衡不同。

## 先准备四类角色

| 角色 | 示例 | 要求 |
| --- | --- | --- |
| 入口 worker | A | 接收客户端连接，入口带宽应覆盖预期聚合速率 |
| 子流端点 | B、C | 提供两条可用传输路径，避免共用同一个窄带瓶颈 |
| TOT 汇聚服务器 | D | 部署相应端点服务，能被各条子流访问，出口带宽充足 |
| 最终目标 | `web.example.com:443` | 提供待访问的实际服务 |

```text
客户端 → A ─┬→ B ─┬→ D → 目标
            └→ C ─┘
```

分别添加并部署 B、C、D，确认在线与可达；入口安装 worker。安装命令使用各自记录生成的命令，不要复用其他节点的 Token。

## 第一步：在端口中选择 TOT 聚合

进入 **端口管理 → 添加端口转发**，选择入口线路、填写目标和服务端口。展开 **转发配置 → TOT 聚合**：

1. 选择 D 为 **Tot 服务器**。
2. 核对汇聚服务器的均衡策略和测试方法。
3. 要做带宽叠加，发送模式选 **聚合模式**。
4. 在 **TOT 子流**添加实际路径。

![TOT 汇聚服务器、发送模式和子流编辑器](https://img.coderluny.com:444/uploads/zfc-tutorial-20261018-tot-substream-f27ec476daca.png)

为 B、C 两条并行路径分别添加并配置子流卡片。

## 第二步：选择子流类型

| 子流类型 | 配置方式 | 含义 |
| --- | --- | --- |
| 多端点优选 | 每张卡片选择至少一个候选端点 | 从该卡片候选池选路径；单端点是只有一个候选的情况 |
| 链式转发 | 按顺序选择至少两个端点 | 这条子流先经过多个端点，再连接汇聚服务器 |

最简单的两路径示例：子流 `#1` 选择 B，子流 `#2` 选择 C。不要只在同一张“多端点优选”卡片中选择 B 和 C，就认为已创建两条独立并行子流。

TOT 至少需要一条有效子流；多条子流才能体现此示例的多路径聚合。删除空卡片，确保各条路径都能到达 D。

## 第三步：按需调整子流进阶设置

![子流的复用次数、方向、带宽、权重与生效时间](https://img.coderluny.com:444/uploads/zfc-tutorial-20261018-tot-advanced-4528f66a5c87.png)

- **子流复用次数**：为该子流建立并行连接；先用默认设置确认基本可用。
- **流量方向**：双向、仅上行或仅下行。不能全部设为同一单向，另一方向也要有子流承载。
- **子流带宽**：单位 Mbps，`0` 表示不限；多条复用连接共用该子流总额。
- **选择权重**：子流数量超过聚合上限时影响入选概率，不代表选中后的流量分配比例；开启复用时还受聚合上限约束。
- **生效时间**：按界面显示时区配置，检查计划之外是否仍有可用子流。

不同带宽路径可按物理带宽设置子流带宽，避免慢路径拖累整体效率。路径上的每个实际转发端点仍可能计费。

## 服务器级默认聚合

也可以在 **服务器管理 → 添加 / 编辑 → 转发配置**中选择 TOT，并配置汇聚服务器与子流。要让端口业务默认使用它，需开启 **使用转发端点作为传输**，再检查端口是否覆盖了路径。

已有 worker 修改转发配置后保存并确认同步即可，不必因为改成聚合模式就再次安装。节点安装与更新按面板为该记录提供的指引操作。

## 验证单连接效果

1. 分别测 B、C 路径单独使用时的实际吞吐。
2. 保存 TOT 规则后，用同一目标、相近时间和相同测试条件测单连接。
3. 观察入口、子流和汇聚点的带宽、丢包、CPU 与流量限额。
4. 需要多连接吞吐时另做测试，避免把多连接结果当成单连接聚合效果。
5. 在测试环境验证单条子流故障与恢复。

两条 100 Mbps 路径的容量相加是理论上限；实际速率受入口、汇聚、目标、共享链路、丢包和限速影响，不能保证达到 200 Mbps。复制模式用于冗余传输，会增加流量，不应按聚合模式的带宽收益估算。

## 常见问题

| 现象 | 优先检查 |
| --- | --- |
| 选择 TOT 后不能保存 | 汇聚服务器、子流数量、每张卡片的端点和权限 |
| 链式子流校验失败 | 是否至少选择两跳，顺序是否可达 |
| 一个方向不通 | 是否把所有子流设为仅上行或仅下行 |
| 总吞吐仍受一条小带宽限制 | 入口 / 汇聚 / 目标瓶颈、共享上游、各层限速 |
| 流量比预期大 | 发送模式是否为复制、路径多跳计费、测速流量 |
