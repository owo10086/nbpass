# RelayX

企业级多协议隧道代理运营平台

[开始使用](guide/intro/index.md)

### 简单易用

RelayX 隧道管理面板采用直观的设计理念，提供一键式隧道创建和管理功能。 无论是新手还是专业用户，都能快速上手并高效管理网络隧道连接。

### 安全可靠

采用企业级安全标准，支持多种加密协议和认证方式。 提供实时监控、流量统计和异常检测，确保您的网络连接安全稳定。

### 高性能架构

基于现代化微服务架构构建，支持高并发连接和负载均衡。 提供实时状态监控、智能路由选择和自动故障转移功能。
