# 面板配置

面板部署后，第一个注册的账号就是管理员账号。如果需要添加管理员账号，可以进入到管理后台进行添加。

## [配置站点和购买 License](site/index.md)

配置站点信息

## [配置支付方式（商业版）](payment/index.md)

支付服务仅支持商业版，个人版无法使用。

## [创建节点组](node-group/index.md)

节点组是多个节点的集合，分为入口节点组和出口节点组，同一节点组下的节点读取相同配置。

## [配置套餐](plan/index.md)

套餐是配置用户购买后可以使用的功能、节点、流量等。

## [角色权限](rbac/index.md)

面板部署后，第一个注册的账号即「超级管理员」，拥有全部后台权限。如果你需要让其他账号协助管理后台，但又不想把全部权限都交出去，可以使用 RBAC 角色权限 按需把后台模块的访问权限委派出去。
