<a id="购买-license"></a>

## 购买 License

你需要购买 License 才能使用完整功能，**多次购买会延长有效期**。

> **注意**
>
> license 购买后将绑定到你的站点地址，即你在 [部署面板](../../deploy-dash/index.md#%E4%BD%BF%E7%94%A8-docker-compose-%E9%83%A8%E7%BD%B2) 中配置的站点地址 `SITE_URL`，无法在其他站点使用。
