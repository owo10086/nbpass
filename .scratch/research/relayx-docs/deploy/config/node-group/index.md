# 创建节点组

节点组是多个节点的集合，分为入口节点组和出口节点组，同一节点组下的节点读取相同配置。

![节点组](https://docs.relayx.cc/assets/images/node-group-442d120a067fa72857672943c8003012.png)

**通用配置**：

- **端口范围**：节点组可以使用的端口范围，可用于限制节点组可以使用的端口，以及对于 NAT 机器可以限制端口范围。
- **允许隧道协议**：节点组可以使用的隧道协议。

**入口节点组配置**：

- **是否需要出口节点组**：隧道创建时是否需要出口节点组，如果不需要，则可以直接从入口节点转发到目标网络。
- **连接 IP**：用户可以看到的连接地址，可以用过域名解析实现 DNS 负载均衡。

**出口节点组配置**：

- **负载均衡方式**：

  - 轮询：按照顺序轮流转发到不同的出口节点。
  - 随机：随机转发到不同的出口节点。
  - FIFO：自上而下，主备模式。
  - 哈希：根据用户 IP 哈希转发到不同的出口节点。
  - 最小延迟：选择延迟最低的出口节点。
  - 最小连接数：选择当前连接数最少的出口节点。

### 架构说明

- **用户端**：多个用户/客户端需要连接服务
- **DNS 解析**：通过 DNS 解析实现负载均衡，将用户请求分发到不同的入口节点
- **入口节点组**：用户直接连接的节点组，同一节点组内的多个入口节点共享相同配置，通过 DNS 解析实现负载均衡
- **出口节点组**：连接到用户节点的节点组，多个出口节点组成负载均衡，每个入口节点都可以连接到任意出口节点
- **目标网络**：最终的目标服务器或服务
