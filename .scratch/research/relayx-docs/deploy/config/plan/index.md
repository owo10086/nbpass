# 配置套餐

套餐是配置用户购买后可以使用的功能、节点、流量等。

![套餐](https://docs.relayx.cc/assets/images/plan-ba0f27acfacfe3ec6d4f85dc1260518c.png)

- **最大隧道数**：用户购买后可以创建的隧道数量。
- **流量**：用户购买后可以使用的流量，单位为 GB，目前我们是双向统计。
- **并发连接数**：单个隧道最大连接数。
- **带宽限制**：单个隧道最大的带宽。
- **允许自定义入口节点组**：开启后用户自己对接自己的入口节点。
- **允许自定义出口节点组**：开启后用户自己对接自己的出口节点。
- **允许使用所有入站节点组**：开启后用户可以使用所有入站节点组。
- **允许使用所有出站节点组**：开启后用户可以使用所有出站节点组。
- **节点组**：用户可以使用的节点组，跟允许所有入站节点组和允许所有出站节点组的配置互斥。
- **允许续费**：关闭后用户无法续费，开启后即使套餐不可见，用户也可以续费。

恭喜！所有配置均已完成，你的站点现在可以正常使用了。
