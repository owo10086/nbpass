# 支付服务 (商业版)

> **注意**
>
> 支付服务仅支持商业版，个人版无法使用。

我们目前支持两种支付方式：

- 易支付
- BEPUSDT

易支付没啥好说的，大部分 TG 上的支付都是易支付。

BEPUSDT 是一个加密货币支付网关，支持 USDT(TRC20)、TRX、USDT(Polygon)。

使用教程和部署教程可以参考：[https://github.com/v03413/bepusdt](https://github.com/v03413/bepusdt)
