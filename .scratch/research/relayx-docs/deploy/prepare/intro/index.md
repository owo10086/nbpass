# 准备说明

- 一台服务器，配置 1C2G 以上，越高越好。
- 一个域名，并且解析到服务器上。
- MySQL 8 以上，自行部署或选择云服务。
- Redis，自行部署或选择云服务。
- 邮件发送服务 SMTP，自行部署或选择 SaaS 服务，比如：[Resend](https://resend.com)。
- StackAuth 服务，用来管理用户登录注册，推荐直接使用 SaaS 服务，地址：[https://stack-auth.com](https://stack-auth.com)，月活用户 1W 以下免费。
- 支付服务，当前支持易支付和 [BEPUSDT](https://github.com/v03413/bepusdt)。
- Telegram 机器人，用来发送通知。
- 当然最重要的，动手能力。
