# 数据库

在 [部署文档](../../deploy-dash/index.md) 中，我们提供的 `compose.yaml` 文件，已经自带了 MySQL 和 Redis，你可以不用自己部署。

<a id="mysql"></a>

## MySQL

我们使用 MySQL 8 以上版本，可以自行部署或选择云服务。具体部署文档网上有很多，这里不再赘述。

<a id="redis"></a>

## Redis

Redis 版本不强制要求，但是推荐最新版本。具体部署文档网上有很多，这里不再赘述。
