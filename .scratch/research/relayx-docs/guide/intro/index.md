# 介绍

RelayX 是一款功能强大的隧道管理面板。

<a id="功能"></a>

## 功能

- 用户管理，支持多种登录方式，如邮箱、Google、Passkey 等
- 隧道管理，支持多种隧道协议，如 TCP、UDP、WSS、TLS、QUIC、RelayX 等
- 隧道链，支持多跳转发，灵活的网络架构
- 统计分析，流量统计、支付统计、用户统计等
- 支付管理，支持多种支付方式，如易支付、BEPUSDT、Heleket 等
- 套餐管理，丰富的套餐功能配置，支持优惠券
- 节点状态监控，实时监控节点 CPU、内存、网络等指标
- 节点组与节点管理，支持六种负载均衡策略
- DNS 管理，支持 Cloudflare、阿里云等多种 DNS 提供商，自动保活
- 工单系统，用户与管理员便捷沟通
- 推荐返佣，邀请用户获得佣金奖励
- API 接口，支持通过 API Key 自动化管理
