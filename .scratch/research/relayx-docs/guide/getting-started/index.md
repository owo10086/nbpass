# 开始使用

## [登录注册](login/index.md)

我们提供了多种登录方式，包括：

## [购买套餐](plan/index.md)

所有的权益都是与套餐绑定的，比如隧道数量、流量、网速等。所以需要先购买套餐。

## [创建节点组](node-group/index.md)

节点组是若干节点的集合，同一个节点组里面的节点共享相同的配置，包括监听地址、端口、协议等。

## [部署节点](deploy-node/index.md)

当创建好节点组后，需要部署节点。点击节点组列表的「部署节点」按钮。

## [创建隧道](tunnel/index.md)

当节点部署完成后，可以点击节点组列表的「创建隧道」按钮，进入创建隧道页面。

## [账户管理](account/index.md)

注册登录后，点击侧边栏的「个人中心」进入账户管理页面。

## [DNS 管理](dns/index.md)

RelayX 支持配置 DNS 提供商来实现入口节点组的 DNS 解析管理和节点存活检测。

## [工单系统](ticket/index.md)

RelayX 内置工单系统，用于用户与管理员之间的沟通。

## [推荐返佣](referral/index.md)

RelayX 提供推荐返佣功能，邀请新用户注册并消费，你可以获得佣金奖励。
