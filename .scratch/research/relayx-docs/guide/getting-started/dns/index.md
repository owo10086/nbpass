# DNS 管理

RelayX 支持配置 DNS 提供商来实现入口节点组的 DNS 解析管理和节点存活检测。

<a id="dns-提供商"></a>

## DNS 提供商

<a id="支持的提供商"></a>

### 支持的提供商

目前支持以下 DNS 提供商：

| 提供商 | 说明 |
| --- | --- |
| **Cloudflare** | 全球知名 DNS 服务商，推荐使用 |
| **阿里云 DNS** | 阿里云 DNS 解析服务 |
| **DNSPod** | 腾讯云旗下 DNS 解析服务 |
| **DNSLA** | DNSLA DNS 解析服务 |
| **华为云 DNS** | 华为云 DNS 解析服务 |
| **Akamai** | Akamai DNS 解析服务 |

<a id="添加-dns-提供商"></a>

### 添加 DNS 提供商

1. 点击侧边栏的「认证配置」
2. 点击「添加」按钮
3. 选择 DNS 提供商类型
4. 填写对应的 API 认证信息（如 Cloudflare 的 API Token）
5. 保存配置

<a id="入口节点组-dns-保活"></a>

## 入口节点组 DNS 保活

DNS 保活功能用于自动管理入口节点组的 DNS 记录，当节点上线或下线时自动更新 DNS 解析记录，实现 DNS 级别的负载均衡和故障转移。

<a id="配置步骤"></a>

### 配置步骤

1. 点击侧边栏的「端点保活」
2. 点击「添加」按钮
3. 选择入口节点组
4. 选择已配置的 DNS 提供商
5. 填写域名和相关配置
6. 保存

<a id="同步-dns-记录"></a>

### 同步 DNS 记录

配置完成后，可以点击「同步」按钮手动将当前节点的 DNS 记录推送到 DNS 提供商。系统也会在节点状态变化时自动同步。

<a id="工作原理"></a>

### 工作原理

当节点离线时，系统会自动从 DNS 记录中移除该节点的 IP，确保用户始终连接到可用的节点。
