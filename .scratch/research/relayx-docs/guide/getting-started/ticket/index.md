# 工单系统

RelayX 内置工单系统，用于用户与管理员之间的沟通。

> **信息**
>
> 工单系统需要商业授权才能使用。

<a id="创建工单"></a>

## 创建工单

1. 点击侧边栏的「工单」
2. 点击「新建工单」按钮
3. 填写工单标题和内容描述
4. 提交工单

<a id="工单状态"></a>

## 工单状态

工单有以下状态：

- **开启中**：工单已创建，等待处理或正在沟通中
- **已关闭**：工单已解决或关闭

<a id="回复工单"></a>

## 回复工单

在工单详情页面可以查看完整的沟通记录，并添加新的回复。管理员和用户都可以在工单中回复。

<a id="关闭工单"></a>

## 关闭工单

问题解决后，用户或管理员都可以关闭工单。如果需要重新讨论，可以重新打开已关闭的工单。
