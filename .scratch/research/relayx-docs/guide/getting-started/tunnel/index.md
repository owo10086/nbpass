# 创建隧道

当节点部署完成后，可以点击节点组列表的「创建隧道」按钮，进入创建隧道页面。

![创建隧道](https://docs.relayx.cc/assets/images/tunnel-9e5b58078c2d79241f4f49fed74cef64.png)

- **隧道名称**：隧道的名称，用于标识该隧道
- **隧道协议**：隧道的协议，当前支持 TCP、MTCP、UDP、WSS、MWSS、TLS、MTLS、QUIC、RelayX 等多种类型，详见 [隧道协议详解](../../advanced/protocol/index.md)
- **入口监听地址**：为空则监听所有地址，否则监听指定地址，TCP、UDP 同时监听
- **端口号**：监听端口，为空则随机分配
- **入口节点组**：选择入口节点组
- **出口节点组**：选择出口节点组，如果入口节点组配置了不需要出口节点组，则该选项可以为空
- **负载均衡方式**：目前支持轮询、主备、随机、哈希、最小延迟、最小连接数六种负载均衡方式

  - 轮询：按照顺序轮流转发到每个出口节点
  - 主备：按照顺序转发到每个出口节点，如果当前出口节点不可用，则转发到下一个出口节点
  - 随机：随机转发到每个出口节点
  - 哈希：根据客户端 IP 哈希转发到出口节点
  - 最小延迟：选择延迟最低的出口节点
  - 最小连接数：选择当前连接数最少的出口节点
- **IP 类型**：入口和出口连接的 IP 类型，如果指定类型的 IP 不存在，则自动选择一个 IP
- **启用 Proxy Protocol**：启用后，会使用 Proxy Protocol 协议，用于获取客户端的真实 IP
- **入口监听协议**：入口节点对客户端暴露的应用层协议，可选 TCP/UDP（默认）、HTTP、SOCKS5、Shadowsocks、Relay、WireGuard、OpenVPN。仅当入口节点组开启「允许入口监听协议」时生效，详见 [入口监听协议与转发地址协议](../../advanced/protocol/index.md#%E5%85%A5%E5%8F%A3%E7%9B%91%E5%90%AC%E5%8D%8F%E8%AE%AE%E4%B8%8E%E8%BD%AC%E5%8F%91%E5%9C%B0%E5%9D%80%E5%8D%8F%E8%AE%AE)
- **转发地址协议**：连接转发地址（目标服务）时使用的应用层协议，可选 TCP/UDP（默认）、HTTP、SOCKS5、Shadowsocks、Relay。配合入口监听协议可实现**协议转换**
- **转发地址**：可以配置多个转发地址，以及对应的负载均衡权重，权重只对随机负载均衡方式有效

## 隧道图示

<a id="带出口节点组"></a>

### 带出口节点组

在带出口节点组的模式下，数据流向为：客户端 → 入口节点组 → 出口节点组 → 目标服务。这种模式适用于需要在不同地理位置或网络环境之间进行转发的场景。

<a id="不带出口节点组"></a>

### 不带出口节点组

在不带出口节点组的模式下，数据流向为：客户端 → 入口节点组 → 目标服务。这种模式适用于简单的负载均衡或反向代理场景，入口节点直接转发到目标服务。
