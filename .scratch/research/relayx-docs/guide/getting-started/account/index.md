# 账户管理

注册登录后，点击侧边栏的「个人中心」进入账户管理页面。

<a id="基本信息"></a>

## 基本信息

账户管理页面显示以下信息：

- **邮箱**：当前登录的邮箱地址
- **余额**：账户余额，用于购买套餐和续费
- **当前套餐**：显示套餐名称、计费周期、流量使用情况、最大隧道数、到期时间等

<a id="充值"></a>

## 充值

点击「充值」按钮，选择充值金额和支付方式进行充值。充值成功后余额会自动更新。

如果当前有充值活动（如额外赠送比例或固定金额），会在充值页面显示。

<a id="套餐续费"></a>

## 套餐续费

如果当前已有套餐，可以点击「续费」按钮进行续费，续费会在当前到期时间基础上延长。

<a id="自动续费"></a>

### 自动续费

开启自动续费后，套餐到期时系统会自动从账户余额中扣费续费。如果余额不足则续费失败。

<a id="订阅-key"></a>

## 订阅 Key

订阅 Key 用于生成订阅链接，可随时查看和复制。

- 点击「复制」按钮可以复制订阅 Key
- 点击「重置」按钮可以重新生成订阅 Key（旧的订阅地址会立即失效）

<a id="api-key"></a>

## API Key

API Key 用于通过 API 接口访问 RelayX 服务，详见 [API 使用指南](../../advanced/api/index.md)。

出于安全考虑，API Key **仅在重置时显示一次**，关闭后将无法再次查看。

- 点击「重置」按钮可以重新生成 API Key（旧的 Key 会立即失效）
- 请立即复制并妥善保存，如需再次查看只能重新重置

> **警告**
>
> 重置 API Key 后，所有使用旧 Key 的请求都会失败，请及时更新。

<a id="绑定-telegram"></a>

## 绑定 Telegram

绑定 Telegram 后，可以通过 Telegram Bot 接收系统通知（如套餐到期提醒、充值成功通知等）。

1. 在账户管理页面找到 Telegram 绑定区域
2. 点击绑定按钮，会跳转到 Telegram Bot
3. 在 Bot 中发送绑定指令完成绑定

<a id="通知设置"></a>

## 通知设置

可以自定义接收通知的方式和类型，包括：

- 邮件通知
- Telegram 通知（需先绑定 Telegram）

节点注册、断开连接和恢复在线通知仅通过 Telegram 发送，不支持邮件通知。

<a id="流量统计"></a>

## 流量统计

账户管理页面还展示了流量统计图表，可以按以下维度查看：

- **日统计**：查看每天的流量使用情况
- **月统计**：查看每月的流量使用情况
- **年统计**：查看每年的流量使用情况

<a id="余额明细"></a>

## 余额明细

点击侧边栏的「余额明细」可以查看所有余额变动记录，包括：

- 充值记录
- 套餐消费记录
- 推荐佣金收入
