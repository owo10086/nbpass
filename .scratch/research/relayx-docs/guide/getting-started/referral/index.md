# 推荐返佣

RelayX 提供推荐返佣功能，邀请新用户注册并消费，你可以获得佣金奖励。

> **信息**
>
> 推荐返佣功能需要商业授权才能使用。

<a id="获取推荐链接"></a>

## 获取推荐链接

1. 点击侧边栏的「推荐返佣」
2. 复制你的专属推荐链接

当其他用户通过你的推荐链接注册后，该用户会自动绑定为你的下级用户。

<a id="佣金规则"></a>

## 佣金规则

- 当你推荐的用户充值时，你将获得充值金额一定比例的佣金
- 佣金比例由管理员在后台配置
- 佣金会自动充入你的账户余额

<a id="统计数据"></a>

## 统计数据

在推荐返佣页面可以查看：

- **推荐人数**：通过你的链接注册的用户总数
- **佣金总额**：累计获得的佣金金额
- **佣金趋势**：按时间维度查看佣金收入变化
