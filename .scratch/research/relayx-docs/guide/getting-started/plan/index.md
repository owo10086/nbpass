# 购买套餐

所有的权益都是与套餐绑定的，比如隧道数量、流量、网速等。所以需要先购买套餐。

<a id="充值余额"></a>

## 充值余额

需要先充值余额，才能购买套餐。

![充值](https://docs.relayx.cc/assets/images/topup-849bdd98188209c598023e6d0d4864b3.png)

<a id="购买"></a>

## 购买

你可以按照自己的需求购买套餐。目前 SaaS 版提供四种套餐，分别是：

- 免费套餐：永久免费，允许创建 5 个隧道
- 月付套餐：36 元/月
- 半年付套餐：200 元/半年
- 年付套餐：360 元/年

所有付费套餐权益相同，无任何限制。
