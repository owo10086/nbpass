# 隧道链（多跳转发）

隧道链功能允许在入口节点和出口节点之间添加中间节点组，实现多跳转发。数据流经多个节点组后到达目标服务，适用于复杂的网络架构需求。

<a id="工作原理"></a>

## 工作原理

<a id="普通隧道无隧道链"></a>

### 普通隧道（无隧道链）

<a id="带隧道链的隧道"></a>

### 带隧道链的隧道

隧道链允许你在入口和出口之间插入一个或多个中转节点组，数据会依次经过每个中转节点组进行转发。

<a id="使用场景"></a>

## 使用场景

- **跨地域优化**：通过中间节点优化跨地域的网络路径，降低延迟
- **网络隔离**：不同网络区域之间需要中间节点作为跳板
- **多层负载均衡**：在不同层级进行负载均衡

<a id="配置方法"></a>

## 配置方法

在创建或编辑隧道时，可以添加隧道链：

1. 创建隧道并设置入口和出口节点组
2. 在隧道配置中添加中间节点组
3. 设置每个中间节点组的类型（入口/出口）
4. 保存隧道

## 图示

> **警告**
>
> 隧道链中每增加一跳都会增加额外的延迟，同时中转节点组的流量也会计入流量消耗。请根据实际需要合理配置跳数。
