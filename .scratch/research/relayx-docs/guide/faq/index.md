# 常见问题

<a id="账户相关"></a>

## 账户相关

<a id="支持哪些登录方式"></a>

### 支持哪些登录方式？

RelayX 支持以下登录方式：

- 邮箱验证码登录
- Google 账号登录
- Passkey（密钥）登录

具体支持哪些方式取决于管理员的配置。

<a id="忘记密码怎么办"></a>

### 忘记密码怎么办？

RelayX 使用邮箱验证码登录，无需密码。使用注册时的邮箱即可重新登录。

<a id="api-key-泄露了怎么办"></a>

### API Key 泄露了怎么办？

立即前往「个人中心」重置 API Key，重置后旧 Key 会立即失效。新 Key 仅显示一次，请立即复制保存。

<a id="订阅-key-泄露了怎么办"></a>

### 订阅 Key 泄露了怎么办？

立即前往「个人中心」重置订阅 Key，重置后旧的订阅地址会立即失效，需要重新导入订阅。订阅 Key 与 API Key 相互独立，重置其一不会影响另一个。

<a id="套餐相关"></a>

## 套餐相关

<a id="套餐到期后隧道还能用吗"></a>

### 套餐到期后隧道还能用吗？

套餐到期后隧道会停止转发。建议开启自动续费，避免服务中断。

<a id="如何升级降级套餐"></a>

### 如何升级/降级套餐？

目前需要等当前套餐到期后再购买新套餐。

<a id="流量用完了怎么办"></a>

### 流量用完了怎么办？

流量用完后隧道会停止转发，需要续费或等待下个周期重置。

<a id="隧道相关"></a>

## 隧道相关

<a id="隧道连接不上怎么排查"></a>

### 隧道连接不上怎么排查？

1. **检查节点状态**：确认入口和出口节点均在线
2. **检查端口**：确认监听端口没有被防火墙拦截
3. **检查转发地址**：确认目标服务可以从出口节点正常访问
4. **检查协议**：确认使用的协议没有被网络封锁
5. **查看隧道状态**：在「隧道状态」页面查看实时状态

<a id="如何选择合适的隧道协议"></a>

### 如何选择合适的隧道协议？

参考 [隧道协议详解](../advanced/protocol/index.md) 中的协议选择建议。一般推荐使用 RelayX 协议。

<a id="端口号如何分配"></a>

### 端口号如何分配？

- 如果填写了端口号，将使用指定的端口（需在节点组允许的端口范围内）
- 如果不填写端口号，系统会在允许的端口范围内随机分配

<a id="一个隧道可以转发到多个目标地址吗"></a>

### 一个隧道可以转发到多个目标地址吗？

可以。创建隧道时可以配置多个转发地址，系统会根据负载均衡策略分配流量。每个转发地址可以设置不同的权重。

<a id="什么是-proxy-protocol"></a>

### 什么是 Proxy Protocol？

Proxy Protocol 是一种获取客户端真实 IP 地址的协议。开启后，转发的数据包中会携带客户端的原始 IP 信息。目标服务需要支持 Proxy Protocol 才能正确解析。

<a id="节点相关"></a>

## 节点相关

<a id="节点显示离线怎么办"></a>

### 节点显示离线怎么办？

1. 检查节点服务器是否正常运行
2. 检查节点上的 RelayX Agent 服务是否运行中
3. 检查服务器防火墙是否放行了相关端口
4. 查看 Agent 日志排查具体错误

<a id="如何升级节点"></a>

### 如何升级节点？

在节点管理页面点击「升级」按钮，系统会自动将所有节点升级到最新版本。也可以在节点部署页面重新运行部署命令。

<a id="节点流量统计不准确"></a>

### 节点流量统计不准确？

默认使用系统级别的流量统计，重启后会清零。推荐安装 vnstat 进行持久化的流量统计，详见 [部署节点](../getting-started/deploy-node/index.md) 中的流量统计部分。

<a id="部署相关"></a>

## 部署相关

<a id="docker-启动报错怎么办"></a>

### Docker 启动报错怎么办？

1. 确认 Docker 和 Docker Compose 版本符合要求
2. 检查 `.env` 文件中的配置是否正确
3. 检查端口是否被占用：`docker compose logs -f`
4. 检查数据库连接是否正常

<a id="如何升级-relayx-面板"></a>

### 如何升级 RelayX 面板？

```bash
docker compose down && docker compose up -d --pull always
```

此命令会拉取最新镜像并重新启动服务，数据不会丢失。

<a id="https-证书如何配置"></a>

### HTTPS 证书如何配置？

默认使用 Caddy 自动申请和续期 HTTPS 证书，无需手动配置。如果使用 Nginx，需要自行配置 SSL 证书。

<a id="如何备份数据"></a>

### 如何备份数据？

建议定期备份 MySQL 数据库：

```bash
docker compose exec mysql mysqldump -u root -p relayx > backup.sql
```

恢复数据：

```bash
docker compose exec -i mysql mysql -u root -p relayx < backup.sql
```

<a id="支付相关"></a>

## 支付相关

<a id="支持哪些支付方式"></a>

### 支持哪些支付方式？

根据管理员配置，支持以下支付方式：

- **易支付**：常见的聚合支付方式
- **BEPUSDT**：加密货币支付（USDT TRC20 等）
- **Heleket**：第三方支付网关

<a id="充值后余额没有到账"></a>

### 充值后余额没有到账？

1. 检查支付是否真正完成（查看支付平台的订单状态）
2. 等待几分钟，支付回调可能有延迟
3. 如仍未到账，请提交工单联系管理员
