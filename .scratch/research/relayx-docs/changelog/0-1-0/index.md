### 🚀 新功能

- 支持同一个机器部署多个节点，使用 `-S` 参数指定服务名称
- 支持卸载指定节点，使用 `-S` 参数指定服务名称
- 现在你可以指定 docker image tag 来拉取指定版本的镜像，如：relayx/backend:0.1.0
