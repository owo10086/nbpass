# 0.3.0

2025年6月9日

> **注意**
>
> 本次更新有数据库更改，请执行：`docker compose down` 然后 `docker compose up -d --pull always`

<a id="rocket-新功能"></a>

### 🚀 新功能

- 支持在线升级节点 （需要更新最新节点端后续才会生效）
- 支持批量更新隧道 Proxy Protocol 配置
- 支持一键启用/停用隧道

<a id="nail_care-优化"></a>

### 💅 优化

- 优化节点升级命令
- 优化离线节点清理
- 优化节点批量导入功能
