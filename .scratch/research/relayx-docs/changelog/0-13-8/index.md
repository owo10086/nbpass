# 0.13.8

2026年4月22日

<a id="nail_care-优化"></a>

### 💅 优化

- 用户通知设置支持分别开关邮件和 Telegram 渠道
- 管理员通知（用户充值、工单创建、工单回复）支持按管理员独立配置邮件和 Telegram 渠道，默认全部开启

<a id="bug-修复"></a>

### 🐛 修复

- 修复隧道状态列表输入/输出网速显示错误，现已按流量上报周期换算为每秒速率
- 隧道测试超时和 agent 连接不稳定的问题（需要更新节点端 0.13.9 版本）
