# 0.13.2

2026年3月19日

<a id="rocket-新功能"></a>

### 🚀 新功能

- 套餐支持设置费（setup\_fee），仅首次购买时收取，续费不收取
- 推广返利支持选择返利模式：充值返利或购买套餐返利
- 推广返利支持「仅首次返利」开关，开启后仅首次充值或购买套餐时返利
- 系统设置新增「返利配置」独立分组
