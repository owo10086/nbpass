# 0.13.5

2026年4月7日

<a id="rocket-新功能"></a>

### 🚀 新功能

- 新增佣金余额，佣金余额可以划转或提现

<a id="nail_care-优化"></a>

### 💅 优化

- 节点注册时校验用户套餐是否允许自定义入口/出口节点组，不允许时拒绝注册
- 隧道状态新增当前 IP 数展示
- 套餐和隧道支持配置 IP 数量限制
- 连接数限制/带宽限制/IP 数量限制支持配置为入口级别、账户级别 （需要更新节点端 0.13.4 版本）
- 节点端支持更多系统（alpine、openwrt 等等）
