# 0.13.3

2026年3月22日

<a id="rocket-新功能"></a>

### 🚀 新功能

- 入口节点组支持启用隧道白名单（Admission），开启后用户可在隧道中配置 IP 白名单，仅允许指定 IP 访问
- 管理员控制台新增「新增用户统计」面板，支持按天/月/年聚合和日期范围筛选
- 管理员控制台新增「流量统计」面板，支持按天/月/年聚合、入口节点组、出口节点组和日期范围筛选
- 用户支持单独配置返利比例和仅首次返利，未配置时使用系统全局配置

<a id="nail_care-优化"></a>

### 💅 优化

- 用户端和管理端节点管理增加节点类型（入口/出口）筛选
