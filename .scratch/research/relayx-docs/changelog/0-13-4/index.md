# 0.13.4

2026年3月31日

<a id="rocket-新功能"></a>

### 🚀 新功能

- 套餐支持配置白名单 IP 数量限制（`whitelist_limit`），用户可在转发列表页统一管理白名单 IP，入口节点组开启准入控制后自动应用
- 入口保活支持备用节点逻辑，仅当所有普通节点不可用时才将备用节点加入 DNS

<a id="nail_care-优化"></a>

### 💅 优化

- 管理员首页替换欢迎卡片为站点信息模块
- License 历史订单改用统一 DataTable 组件，支持分页、排序和筛选（订单号、状态）
- 重构节点状态页面：CPU/内存/磁盘改用进度条展示，详细信息收入 Tooltip，网络速率使用 Badge 展示
- 节点状态页面集成节点管理功能（编辑、删除、卸载、升级），移除独立的节点管理页面
- 节点状态页面仅对用户自己的节点组展示节点 IP
- 移除清理离线节点功能

<a id="bug-修复"></a>

### 🐛 修复

- 修复购买永久 License 订阅时 cycle 校验不通过的问题
