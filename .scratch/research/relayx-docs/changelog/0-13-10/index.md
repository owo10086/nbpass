# 0.13.10

2026年5月5日

<a id="rocket-新功能"></a>

### 🚀 新功能

- Telegram 机器人新增常用管理功能
- 余额和佣金余额调整改为独立操作，并写入日志（新增"管理员调整"类型）
- 增加入口代理协议订阅配置

<a id="nail_care-优化"></a>

### 💅 优化

- 邮件和 Telegram 通知信息更丰富，统一支持跳转按钮
- 用户列表新增佣金余额、自动续费、返利比例、仅首次返利等字段
- 界面交互优化
- 增加入口节点组代理协议配置允许的协议

<a id="bug-修复"></a>

### 🐛 修复

- 修复工单回复未检查用户通知订阅偏好的问题
- 修复 wireguard 相关问题
