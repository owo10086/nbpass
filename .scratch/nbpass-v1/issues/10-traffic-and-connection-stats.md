# 10: 规则流量与连接数统计

**What to build:** 每条规则显示累计上行、下行业务字节和当前连接数，只在入口一侧计量，不计 WSS/yamux 开销。累计计数带节点进程实例标识和序号，面板去重，节点重启或重传不重复计数、不出现负增量；离线期间的流量在重连后补报（最多 24 小时）。

**Blocked by:** 03, 08

**Status:** ready-for-agent

**Refs:** 规格用户故事 37、38；必测场景 9（流量部分）；规格「流量计量」

- [ ] 直连和隧道规则在真实 TCP 传输后，累计字节与实际业务字节一致
- [ ] 节点重启后累计量连续，不出现负增量；同一报告重复投递不重复计数
- [ ] 修改规则保持规则 ID 不变，累计量连续
- [ ] 控制链路断开期间的流量在重连后计入
- [ ] 以上行为由测试台通过面板 HTTP API 验证
- [ ] 规则列表显示流量与连接数（人工验收）
