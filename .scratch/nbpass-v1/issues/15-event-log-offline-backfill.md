# 15: 事件日志与节点离线补报

**What to build:** 面板有统一的事件日志，先记录节点上线、同步失败等事件，后续票继续添加事件类型。节点有有界持久化本地事件队列：离线期间存关键事件，重连后补报，面板按事件 ID 去重，溢出时标记缺口。

**Blocked by:** 02

**Status:** ready-for-agent

**Refs:** 规格用户故事 112、113；规格「事件与通知」「本地事件队列」

- [ ] 事件日志可按节点、类型、时间筛选
- [ ] 节点失联期间产生的事件在重连后出现在日志中，重复投递不重复
- [ ] 节点重启后尚未补报的事件不丢失
- [ ] 本地队列溢出时日志显示缺口；最多补报 24 小时
- [ ] 以上行为由测试台通过面板 HTTP API 验证
- [ ] 事件日志页（人工验收）
