# 22: 多成员入口组与手动切换

**What to build:** 入口组可以有多个成员并排序，第一位是首选入口；规则下发到所有成员。管理员可手动把活动入口切到指定成员，手动操作同样提交到协调器排队；切到非首选成员后，该组显示"自动回切已暂停"，直到管理员手动恢复。界面显示活动入口和受管记录当前值。动作按期望版本排序，迟到的结果核对动作 ID 和版本后才生效。

**Blocked by:** 21

**Status:** ready-for-human

**Refs:** 规格用户故事 58、59（活动入口与记录值部分）、66、66a（暂停部分）；规格「入口动作协调器·手动切换」

- [x] 多成员入口组的规则下发到所有成员，每个成员都监听
- [x] 手动切换后，假 DNSPod 记录为新成员 IP；连续两次手动切换按顺序执行、不互相覆盖
- [x] 迟到的旧动作结果不覆盖新期望
- [x] 切到非首选成员后显示"自动回切已暂停"；手动恢复后清除
- [x] 以上行为由测试台通过面板 HTTP API 与假 DNSPod 验证
- [ ] 入口组详情页：成员排序、活动入口、受管记录当前值、手动切换与恢复按钮（人工验收）
