- **未确认与维护**：面板按注入时钟追踪 3 分钟控制确认期限，超时将活动任务持久化为 `unconfirmed` 并写统一事件，保留原任务和当前程序；面板重启后可继续核对。未确认不算成功、失败或可重复执行的终态，HTTP API 与页面均阻止再次升级。维护仍遵守原 10 分钟期限，确认超时不提前结束或延长维护；维护内切换/换 IP 抑制与到期重新收集证据沿用票 34。
- **完整确认链**：只有当前认证会话的新进程回连，软件版本一致，独立升级报告中的任务完整清单、实例、版本、平台、实际运行程序 SHA256/大小与本地就绪均匹配，并且当前配置已应用，才记 `ready`。Linux 从 `/proc/self/exe` 读取运行映像，避免安装路径被替换后把新路径内容当作旧进程产物。自检结果由本进程重新检查监听、规则及隧道授权；每 10 秒独立重报，业务就绪恢复不依赖更新器阶段或序号变化。相同序号仅刷新进程证据，不能改写任务阶段；升级报告仍不更新活性、配置确认、探针、事件或恢复证据。
- **协议与能力**：新增 `internal/compatibility`。控制协议当前 **2**、接收范围 **1–2**；上一版协议 1 不带新声明时按既有功能标志处理，面板所有回包（含独立升级/换 IP/检测消息）按该会话的协议发送。新增认证管理 API `GET /api/nodes/{id}/compatibility`，返回节点/面板独立兼容范围、会话协议和共同能力，并跨面板重启保存；未接入节点不伪造声明。能力集与旧版能力标志共同限制升级、逐流授权、出口切换、凭据轮换、换 IP 复检和解析采样，未知能力不启用。升级新建与已排队任务的重发都检查当前会话能力和状态格式。
- **隧道与状态格式**：当前与上一版软件共用隧道格式 **1**、本地状态格式 **1**（读范围 1–1、写格式 1），无需为软件版本变化另造数据格式。原 WSS/yamux 线格式及按会话协商的授权预检能力保留。`-update-check` 自检声明独立兼容范围；固定安装器在替换前拒绝不能读当前状态或会写出旧程序无法读取格式的候选。缺少新声明的上一版候选按既有格式 1 兼容。配置缓存不迁移，撤权、配置高水位、事件/流量、自测和换 IP 去重/额度证据均继续保留当前状态，不恢复旧数据目录快照。
