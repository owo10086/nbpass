# 34: 维护中状态与单节点一键升级、回滚

**What to build:** 节点列表标出版本与面板不一致的节点。管理员一键升级单个节点到面板内置的同版本程序：面板生成绑定任务 ID、版本、平台、大小、SHA256 的清单，经已验证的 TLS 下发；独立的更新服务只接受固定产物和固定安装路径，下载、校验、自检后再替换并重启，新版本启动失败或本地业务自检失败时回滚。升级中的节点进入有期限（10 分钟）的维护中，期间离线不触发入口切换和换 IP；到期后按当前证据重新评估。

**Blocked by:** 16, 24, 30

**Status:** ready-for-agent

**Refs:** 规格用户故事 17（维护中部分）、117–121、123；必测场景 8（回滚与维护部分）；规格「升级管理」「节点模块·更新服务」

- [ ] 清单中版本、平台、大小、哈希任一不符时拒绝安装
- [ ] 更新服务拒绝非固定路径和符号链接；从校验完成到替换之间，产物不可被替换
- [ ] 新版本启动失败、本地业务自检失败时都回滚；回滚不恢复已撤销的授权，不丢失换 IP 动作的去重记录
- [ ] 维护中的活动入口离线不触发切换和换 IP；维护期满仍离线时按当前证据重新评估，维护期内累计的离线时长不直接当作故障确认
- [ ] 测试台使用更新服务外部接口的替身；以上行为由测试台通过面板 HTTP API 验证；真实 systemd 替换与回滚列入 Linux 人工验收
- [ ] 版本不一致标记、升级按钮与任务进度（下载、校验、切换、回连、就绪、回滚）（人工验收）
