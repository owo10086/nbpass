# 25: 首选入口自动回切与驻留保护

**What to build:** 首选入口被切走后，它连续 6 次候选检查成功（1 分钟），且当前活动入口已驻留满 2 分钟（从受管记录写入成功起算），就自动切回。真实故障打断驻留保护，立即切走。自动回切已暂停时不切回，管理员手动恢复后才按规则切回。

**Blocked by:** 24

**Status:** ready-for-agent

**Refs:** 规格用户故事 64、65、66a（暂停期间不回切）；必测场景 12；规格「判定汇总·回切窗口」

- [ ] 首选入口恢复不足 1 分钟、或活动入口驻留不足 2 分钟时不回切；两者都满足后切回
- [ ] 回切窗口内任何一次失败、未知或样本过期都中断窗口，不以时间流逝代替成功样本
- [ ] 当前活动入口真实故障时立即切走，不受驻留限制
- [ ] 自动回切已暂停时不回切；手动恢复后按规则回切
- [ ] 以上行为由测试台通过面板 HTTP API 与假 DNSPod 验证
