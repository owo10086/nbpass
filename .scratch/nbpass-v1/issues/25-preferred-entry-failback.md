# 25: 首选入口自动回切与驻留保护

**What to build:** 首选入口被切走后，它连续 6 次候选检查成功（1 分钟），且当前活动入口已驻留满 2 分钟（从受管记录写入成功起算），就自动切回。真实故障打断驻留保护，立即切走。自动回切已暂停时不切回，管理员手动恢复后才按规则切回。

**Blocked by:** 24

**Status:** ready-for-human

**Refs:** 规格用户故事 64、65、66a（暂停期间不回切）；必测场景 12；规格「判定汇总·回切窗口」

- [x] 首选入口恢复不足 1 分钟、或活动入口驻留不足 2 分钟时不回切；两者都满足后切回
- [x] 回切窗口内任何一次失败、未知或样本过期都中断窗口，不以时间流逝代替成功样本
- [x] 当前活动入口真实故障时立即切走，不受驻留限制
- [x] 自动回切已暂停时不回切；手动恢复后按规则回切
- [x] 以上行为由测试台通过面板 HTTP API 与假 DNSPod 验证

- **验收对应与 TDD**：新增九个 HTTP 测试台顶层场景与一个迁移物理场景。`TestEntryFailbackRequiresSixChecksAndTwoMinuteResidence` 的恢复/驻留两个子场景及 `TestEntryFailbackResidenceStartsWhenDNSWriteIsConfirmed` 对应第 1 项；`TestEntryFailbackInterruptedWindowRequiresSixFreshChecks` 覆盖失败、未知、证据过期、缺样、面板重启，对应第 2 项；`TestEntryFailbackResidenceAndPauseDoNotDelayRealFailure` 对应第 3 项；`TestEntryFailbackPauseAndResumeUseTheSameRules` 对应第 4 项。所有业务操作与断言只走面板 HTTP API，使用假 DNSPod 验证记录、写入次数，节点仍是真实 TLS/gRPC/转发/自测/检测代码，对应第 5 项。另覆盖提交期间样本过期回滚、动作存储失败、通知队列失败续投及旧备份待处理回切封存。先观察到满足条件没有回切的 RED，再实现至 GREEN；审查发现的恢复空指针也先由真实备份恢复回归复现 panic，再修复并转绿。
