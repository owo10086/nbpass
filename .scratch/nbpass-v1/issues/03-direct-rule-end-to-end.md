# 03: 单成员入口组上的直连规则端到端转发

**What to build:** 管理员创建只有一个成员的入口组（不绑定 DNS，受管记录处于"未发布"），在上面创建直连规则（监听端口 → 一个 IPv4 或域名目标）。面板编译带单调版本号的配置快照即时推送，节点应用后开始监听，真实 TCP 流量经入口节点到达目标；节点列表分别显示期望配置版本和已应用配置版本。规则可启用、停用、修改、删除，停用或删除后在线入口立即关闭监听和已有连接。

**Blocked by:** 02

**Status:** ready-for-agent

**Refs:** 规格用户故事 19、27、29（直连部分）、33、34（直连部分）、58（单成员）；规格「配置编译器」「转发引擎（入口）」「部署形态」

- [ ] 可创建单成员入口组，不绑定 DNS 也能使用
- [ ] 直连规则目标支持 IPv4 和域名；域名由入口解析，多个 A 记录在尝试预算内依次尝试；私网目标需在规则上显式允许
- [ ] 配置快照带单调版本号和摘要，改动即时推送，另有每 60 秒一次全量同步；旧流、旧版本、旧进程实例的报告不覆盖新状态；删除通过完整快照收敛
- [ ] 节点回报已应用版本，界面分别显示期望版本与已应用版本
- [ ] 测试台用 localhost 真实 TCP 验证：创建后流量通；停用、删除后监听关闭且已有连接断开；修改后按新目标转发
- [ ] 地址字段与地址族分开存储；隧道传输（v1 仅 WSS）、出口策略（v1 仅主备）、DNS 服务商（v1 仅 DNSPod）的枚举在模型中预留
- [ ] 入口组、规则的列表与编辑页面（人工验收）
