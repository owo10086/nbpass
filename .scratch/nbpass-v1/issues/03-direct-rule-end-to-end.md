# 03: 单成员入口组上的直连规则端到端转发

**What to build:** 管理员创建只有一个成员的入口组（不绑定 DNS，受管记录处于"未发布"），在上面创建直连规则（监听端口 → 一个 IPv4 或域名目标）。面板编译带单调版本号的配置快照即时推送，节点应用后开始监听，真实 TCP 流量经入口节点到达目标；节点列表分别显示期望配置版本和已应用配置版本。规则可启用、停用、修改、删除，停用或删除后在线入口立即关闭监听和已有连接。

**Blocked by:** 02

**Status:** ready-for-human

**Refs:** 规格用户故事 19、27、29（直连部分）、33、34（直连部分）、58（单成员）；规格「配置编译器」「转发引擎（入口）」「部署形态」

- [x] 可创建单成员入口组，不绑定 DNS 也能使用
- [x] 直连规则目标支持 IPv4 和域名；域名由入口解析，多个 A 记录在尝试预算内依次尝试；私网目标需在规则上显式允许
- [x] 配置快照带单调版本号和摘要，改动即时推送，另有每 60 秒一次全量同步；旧流、旧版本、旧进程实例的报告不覆盖新状态；删除通过完整快照收敛
- [x] 节点回报已应用版本，界面分别显示期望版本与已应用版本
- [x] 测试台用 localhost 真实 TCP 验证：创建后流量通；停用、删除后监听关闭且已有连接断开；修改后按新目标转发

## Comments

2026-11-09 实施记录（分支 `ticket/03`，仅修改本工作目录；未修改 docs/ 或其他票，未创建工作树）：

- **模型与迁移**：使用迁移版本 **3**，新增 `entry_groups`、有序的 `entry_group_members`、`forward_rules`、`node_snapshots`，并扩展节点应用结果字段。入口组本票只开放一个成员，受管记录为“未发布”，不要求 DNS 绑定。目标的 `target_address` 与 `target_family` 分开存储；`forwarding` 模型预留 `TunnelTransport(wss)`、`ExitStrategy(primary_backup)`、`DNSProvider(dnspod)` 类型和枚举。规则只开放 TCP/IPv4 直连。
- **管理 API**：`GET/POST /api/entry-groups`、`PUT/DELETE /api/entry-groups/{id}`；`GET/POST /api/rules`、`PUT/DELETE /api/rules/{id}`。入口组请求为 `name`、`members:[node_id]`；规则请求为 `name`、`entry_group_id`、`kind:"direct"`、`listen_port`、`target_address`、`target_family:"ipv4"`、`target_port`、`allow_private`、`enabled`。沿用管理员会话、同源校验、严格 JSON 及错误响应约定。仍有关联规则时删除入口组返回 409；不存在的成员或入口组、非法目标、端口、地址族和规则类型返回 400。
- **配置提交与同步**：`mutateForwarding` 在同一事务内保存业务改动、编译所有受影响节点的完整 protobuf 快照并持久化期望版本，提交后通知控制会话即时推送。只在节点实际配置内容改变时递增该节点版本；快照只包含启用规则，缺失代表撤销，最后一条规则删除时仍保存带新版本的空快照。SHA-256 覆盖确定性 protobuf 编码的版本与完整内容，不含摘要自身。控制流独立于活性报告每 **60 秒**全量重发，接入与活性回包也可携带完整快照；不改变版本。沿用 64 KiB 控制消息上限，保存前限制快照为 60 KiB，避免持久化无法下发的配置。
- **应用与报告隔离**：节点校验摘要、版本和规则后应用，全部成功才推进已应用版本，立即报告版本、摘要或应用错误；错误在发送前按完整 UTF-8 字符限制为 1024 字节，防止汇总错误超过 gRPC 上限；未变化的规则保留监听和连接。报告仍按票 02 的 token、流和进程实例隔离，旧版本、超前版本、错误摘要及迟到失败不能覆盖当前成功确认。新进程接入时清除旧进程的应用确认，待实际应用后再确认。正确版本与摘要的心跳能补回丢失的应用确认，同一进程断线重连后可以收敛。节点列表 API/页面分别展示期望与已应用版本，并显示“未同步 / 正常 / 同步失败 / 待确认”和错误原因。
- **数据面**：`forwarding.Engine` 监听 IPv4 `0.0.0.0:listen_port`，使用真实 TCP 双向转发。域名由实际入口解析为 A 记录，只拨解析出的具体 IPv4，逐地址执行私网许可检查，避免拨号阶段再次解析绕过许可。规则必须显式允许 RFC1918、回环、链路本地及共享地址；未指定、组播及全局广播地址始终拒绝。禁用、删除或修改转发配置先撤销旧监听和该规则全部连接、取消拨号，再启动新配置；支持 TCP 半关闭和取消清理。
- **已决定的歧义与范围**：直连的多 A 记录预算采用最多 **3 个不同 IPv4、总计 10 秒、单候选最多 3 秒**，只在交付业务数据前换候选；域名解析占用同一总预算。修改目标或监听配置会断开该规则已有连接；改名称不改变节点配置。不新增 DNS 写入、隧道、端口/循环静态校验或业务容量限制。规格要求的持久缓存、逐规则版本与部分应用状态由票 **04** 接续；本票只有进程内实际状态和整份应用结果，不宣称节点重启离线恢复配置已完成。票 **05** 接续冲突/循环/引用校验，票 **07** 接续资源上限与空闲策略。监听失败本票如实回报，周期同步可重试。
