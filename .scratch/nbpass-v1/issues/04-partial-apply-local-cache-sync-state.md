# 04: 部分应用语义、节点本地缓存与同步状态

**What to build:** 节点逐规则报告实际生效的规则版本和错误（例如端口实际 bind 失败）；"已应用版本"只在整个快照全部应用成功后推进。节点持久化实际生效状态，启动先加载缓存再连接面板，与面板失联时按缓存继续转发。每条规则显示同步状态（未同步、正常、同步失败、待确认），可展开看每个成员节点；失联节点显示待确认。测试台增加"保留磁盘重建节点或面板核心"的生命周期能力。

**Blocked by:** 03

**Status:** ready-for-agent

**Refs:** 规格用户故事 20、21、32；必测场景 15（部分应用部分）；规格「控制服务·部分应用语义」「节点模块·控制客户端与本地缓存」；ADR 0006

- [ ] 端口被外部进程占用时，该规则显示同步失败及具体节点、端口和原因，同一快照中的其他规则正常生效
- [ ] 部分成功时已应用版本不推进；规则和入口组的汇总只要有成员失败或待确认就不显示正常
- [ ] 控制链路断开后节点继续按缓存转发；节点重启后先加载缓存恢复监听
- [ ] 部分应用失败后重启，已停用或删除的规则不复活
- [ ] 失联节点的同步状态显示待确认，不显示正常
- [ ] 测试台支持保留磁盘重建节点核心和面板核心
- [ ] 以上行为由测试台通过面板 HTTP API 与真实 TCP 验证
- [ ] 规则同步状态与逐成员展开视图（人工验收）
