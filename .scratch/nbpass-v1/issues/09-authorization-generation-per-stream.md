# 09: 授权代次与逐流授权

**What to build:** 每条隧道规则有独立的授权代次；出口按"规则 ID + 授权代次"核对每个新业务流的入口身份和授权目标，只拨该规则的那个目标。入口启用新规则或新授权代次之前，必须先收到出口已应用对应授权的确认。删除或停用规则后出口不再接受新流，已有流每秒复查，撤销后断开。

**Blocked by:** 04, 08

**Status:** ready-for-agent

**Refs:** 规格用户故事 34（隧道部分）、44、45；必测场景 10（越权目标、撤销后已有流、离线删除不复活）、14；规格「配置编译器·授权代次」；ADR 0006

- [ ] 出口尚未确认新授权代次时，入口不把它作为该规则的候选，新规则上线没有"全部被拒"的窗口
- [ ] 入口请求非授权目标或冒用其他入口身份时被出口拒绝
- [ ] 删除规则后，出口在 1 秒复查内断开该规则的已有流
- [ ] 无关的配置版本变化不撤销未变更规则的授权，已有流不受影响
- [ ] 入口离线期间删除的隧道规则：出口在线时拦住新流，入口重连后规则不复活
- [ ] 以上行为由测试台通过面板 HTTP API 与真实 TCP 验证
