# 27: 被墙处理策略选择与策略②（仅入口切换）

**What to build:** 入口组可以选择被墙处理策略：仅换 IP、仅入口切换、先入口切换再换 IP。本票让策略②生效，策略①在 30、策略③在 31 实现，实现之前这两个选项不可选。策略②下，活动入口被认定被墙时切到候选成员；没有候选时保持现状并通知，不隐式改为换 IP。被墙成员恢复后按回切规则处理。

**Blocked by:** 18, 25

**Status:** ready-for-agent

**Refs:** 规格用户故事 77（策略②部分）、80；规格「被墙处理策略状态」

- [ ] 活动入口被墙时，假 DNSPod 记录切到候选成员；被墙成员恢复后按回切规则切回
- [ ] 没有候选时记录不变、发通知，不调用换 IP 接口
- [ ] 非活动成员被墙时不切换，只是不再作为候选
- [ ] 以上行为由测试台通过面板 HTTP API 与假 DNSPod 验证
- [ ] 入口组设置中的策略选择（人工验收）
