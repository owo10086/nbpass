# 05: 端口冲突、转发循环与删除引用校验

**What to build:** 保存规则时，面板逐个成员节点检查监听端口冲突（其他规则、隧道监听、检测端口），冲突时指明哪个节点的哪个端口；同一节点加入多个入口组时也不会撞端口。配置编译器拒绝会形成转发循环的配置。删除节点时列出它还被哪些规则、入口组、出口组引用。

**Blocked by:** 03

**Status:** ready-for-agent

**Refs:** 规格用户故事 26、31；规格「部署形态」（转发循环）「配置编译器」「检测端口」

- [ ] 同一节点属于两个入口组，两组规则使用同一监听端口时保存被拒，提示具体节点和端口
- [ ] 节点的隧道监听端口和固定检测端口参与冲突校验（这两个端口先在模型中定义，即使对应功能尚未实现）
- [ ] 规则目标指向本规则自己的入口监听等循环配置被拒
- [ ] 删除仍被引用的节点时返回引用清单，不留下悬空配置
- [ ] 以上行为由测试台通过面板 HTTP API 验证
- [ ] 冲突与引用提示界面（人工验收）
