# 29: 换 IP 结果未确认、动作去重与冻结

**What to build:** 节点调用换 IP 接口前持久化"动作已开始"，同一动作 ID 只调用一次接口，重复投递只恢复观察。接口超时、两个查询源结果不一致、或观察到期仍无法确定时，动作为"结果未确认"：先查 IP 核对，不立即重发；该节点后续的自动换 IP 冻结，直到核对清楚或管理员手动解除。调用后与面板失联只继续观察和记录。手动换 IP 与进行中或结果未确认的换 IP 互斥。

**Blocked by:** 04, 28

**Status:** ready-for-agent

**Refs:** 规格用户故事 91、98（互斥部分）、98a（解除冻结部分）；必测场景 2、16（许可、持久化失败、互斥部分）

- [ ] 接口超时后节点重建或控制断开：同一动作不再调用接口，重连后恢复对同一动作的观察
- [ ] "动作已开始"持久化失败时不调用接口（测试台注入写失败）
- [ ] 同一许可重复投递时不再调用接口
- [ ] 结果无法确定时冻结，界面显示原因；管理员手动解除后恢复
- [ ] 进行中或结果未确认时再次手动触发被拒
- [ ] 以上行为由测试台通过面板 HTTP API 与假换 IP 接口验证
- [ ] 冻结状态与解除按钮（人工验收）
