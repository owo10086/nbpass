# 14: 探针资源监控与分钟曲线

**What to build:** 每个节点的探针每 5 秒采样 CPU、内存、磁盘、网卡收发速率、连接数（业务、隧道、系统 TCP 分开）和运行时长，面板显示实时值，并保存分钟聚合（平均值与最大值），提供最近 24 小时曲线；离线期间显示为缺失。

**Blocked by:** 02

**Status:** ready-for-human

**Refs:** 规格用户故事 108–111；规格「探针存储」「探针采集」

- [x] 面板显示每个节点的实时指标和在线状态，运行时长从节点进程启动起算
- [x] 分钟聚合保存平均值与最大值，提供最近 24 小时曲线
- [x] 离线期间的曲线为缺失而不是零
- [x] 业务连接数、隧道连接数、系统 TCP 连接数分开显示

## Comments

2026-11-09 实施记录（仅当前 `ticket/14` 工作目录；未修改 docs/ 或其他票）：

- **采集与控制流**：新增 `internal/probe` 的 `Collector.Collect(context.Context)` 与 `Connections.Connections()` 接口，分别经 `node.Dependencies.Probe`、`Connections` 注入。测试台默认使用空 OS 采集替身，具体场景注入可控指标，节点仍运行真实核心、TLS 与 gRPC。节点启动即采样，此后独立每 5 秒采样；核心用注入时钟计算进程运行时长，覆盖采集器提供的 uptime。采集错误不阻断控制活性；非法、负数或非有限指标按字段剔除。CPU 百分比限定 0–100。
- **协议与时序**：控制协议版本仍为 1，`NodeReport.probe` 使用字段号 **14**，`probe_only` 使用 **15**，新增 `ProbeSample`（进程内递增序号、指标 map）。可选字段对旧节点兼容；没有探针的旧节点仍可在线，指标保持缺测。探针报告与票 02 的 10 秒活性分开，不推进 `last_seen_at`，也不改变配置应用状态；首报告仍先建立活性。节点传输使用每轮不可变的报告副本。只有当前已认证控制会话的指标可以写入，其身份不取消息自带的节点 ID；凭据撤销和进程替代后不能继续污染指标。
- **持久化与迁移**：原分支使用新增迁移版本 **3**（`internal/panel/probe_migration.go`）；合入 main 后保留地区迁移 3、认证加固迁移 4，将探针追加为迁移 **5**，新增 `probe_realtime` 与 `probe_minutes`。前者保存最近样本、进程实例、序号和接收时间；后者保存每分钟样本数及每个字段的 sum/count/max，不保存原始 5 秒历史。样本去重与两个表的更新在同一事务内完成，按进程实例和序号忽略重传。聚合随样本到达即持久化，面板重启不丢失未结束分钟。并行票若也新增迁移，合并时需统一迁移编号与 protobuf 字段号。
- **API 与界面**：新增管理员认证后的 `GET /api/nodes/{id}/probe`，返回 `fresh`、`sampled_at`、`realtime` 与 `minutes`。时间轴固定 1440 点，含当前未结束分钟，按 UTC 分钟边界、面板接收时间归桶；不采信节点墙上时钟。每点有 `samples`、`average`、`maximum` 和各字段有效 `counts`；平均分母只计该字段的有效样本。空分钟的平均/最大值为 null，部分缺测字段为 null。节点列表新增“查看探针”，详情抽屉每 5 秒刷新，展示在线状态、资源、三类连接数、运行时长，以及可选指标的平均值/最大值曲线；缺测不连线，支持鼠标与滑块查看分钟数据。
- **缺测口径与歧义决定**：断开控制连接即停止展示实时值；采样满 10 秒未更新亦置 `fresh=false`、`realtime=null`，保留最近样本时间供说明。沿用票 02 的在线/离线状态及 90 秒宽限，不将探针缺测等同于节点离线。断线仍采样，但单槽只保留最新值；重连不补报离线历史，不填零、不插值，不在快进或调度延迟后伪造漏采样本。重连不重置 uptime，节点进程重启才归零。窗口采用当前分钟加前 1439 分钟，已经过期的历史不向 API 返回；可配置保留期及磁盘历史清理由票 37 接入，本票不提前实施清理器。
- **Linux 指标口径**：默认采集 `/proc/stat` 的总 CPU 增量（排除重复的 guest/guest_nice，idle 含 iowait）、`MemTotal - MemAvailable`、根文件系统 `/` 已用/总容量、`/proc/net/dev` 所有非 lo 网卡的累计字节增量/实际采样间隔，以及 `/proc/net/tcp{,6}` 的 ESTABLISHED 连接数。CPU/网卡首样本只建立基线，速率缺测；计数回退时缺测并重建基线。系统 TCP 含控制连接，与业务和隧道数量没有相减/推算关系。非 Linux 平台 OS 值保持缺测，进程 uptime 与注入的连接数仍可用。
- **后续接缝与范围**：当前基线没有转发引擎，未注入 `Connections` 时业务与隧道数均为 0；票 03/08/10 应将运行时的逻辑业务连接数与物理隧道连接数接入该接口，不能用系统 TCP 数代替。票 15 可继续扩展独立事件报告，不能把探针单槽当事件队列。票 37 可按 `probe_minutes.minute` 分批删除历史，不清除实时进程/序号去重状态。本票未实现其他票的转发、事件、检测、设置或清理功能。
- **TDD 与审查**：API 缺测用例先以 404 失败，随后 4 个真实节点采集/聚合/重启/离线/错误场景以缺少实时值失败，再实现采集和存储。新增 7 个 HTTP 测试台探针场景，覆盖 5 秒边界、三类连接数、进程 uptime、有效字段分母、最大值、分钟边界、持久化、24 小时窗口、离线恢复、采集失败/非法值/停滞、身份冒充和吊销。独立审查发现历史响应写出期间持有全局控制锁；另一个物理传输回归先复现“慢读者阻塞了凭据撤销”，再将持锁范围缩至会话元数据快照，复核已关闭该问题。测试台业务断言均只经面板 HTTP API；独立白盒仅验证阻塞传输物理属性。
- **最终验证**：`env -u FORCE_COLOR make test` 全绿（npm ci、TypeScript/Vite 构建、节点产物构建、go vet、go test）；`go test -race ./... -count=1` 全绿。另 `go test -race ./internal/clusterharness -run TestProbe -count=10` 与阻塞 HTTP 传输的 race 回归通过。面板和节点均以 `CGO_ENABLED=0 GOOS=linux GOARCH=amd64` 交叉编译成功，`file` 确认为静态链接 x86-64 ELF。`go mod tidy` 仅将既有版本的 x/sys 标记为直接依赖；`git diff --check` 通过。Vite 仍有 AntD 产物超过 500 kB 的非阻断提示，构建成功。
- **生成产物**：protobuf Go 源码需要随协议提交；`web/dist` 与 `internal/nodebundle` 在提交前按要求还原，本票依赖合并后统一重新生成前端与内嵌节点产物（`make build` 或对应 make 目标），否则旧内嵌页面/安装下载不会包含探针功能。
- **开放问题**：无阻塞交付的规格歧义。真实 Linux OS 指标、实际转发引擎计数接入和浏览器视觉仍需人工核验，不能以测试替身通过代替。

人工验收清单（以下尚未执行）：

1. 合并并统一迁移/协议字段后运行 `make build`，经可信 HTTPS 反向代理登录面板并添加真实 Linux amd64 节点；在节点列表点击“查看探针”。确认详情在线状态、最近样本每约 5 秒更新，运行时长接近节点进程启动时间（可用 `ps -o etimes= -p $(pidof nbpass-node)` 对照），重启服务后归零；仅断链/重连不归零。
2. 用 `mpstat 5` 或 `top` 对照 CPU，用 `free -b` 对照总内存与 total-available，用 `df -B1 /` 对照根文件系统已用/总量。用 `ip -s link` 的非 lo 网卡计数相邻差值除间隔对照接收/发送速率，用 `ss -Htn state established | wc -l` 对照系统 TCP（允许采样时刻导致的小幅差异）。首样本 CPU/速率应为空，后续正常；无权限/读取失败不能显示为零。
3. 在接入转发引擎计数接口后建立、关闭直连业务及隧道业务，核对业务连接、物理隧道连接与系统 TCP 分开变化；控制连接不得算入业务连接。无转发业务时，前两项为 0，系统 TCP 可以非零。
4. 连续运行至少 2 分钟并制造资源变化，查看 CPU、内存、磁盘、收发速率、三类连接数与 uptime 曲线。确认可切换指标、平均值与最大值、分钟样本数量、鼠标/滑块读数、桌面及窄屏可用；只有一个样本的分钟也应有可见点。当前分钟持续更新，数据真实为 0 时应落在零线上。
5. 断开节点控制网络至少 3 分钟：实时值立即变为缺测，90 秒后沿用现有离线标签，中间没有样本的完整分钟应为空白。恢复后新样本继续记录，离线区段仍为空白；重启面板后既有平均/最大值保持，未重新接入前不能把持久化旧值标为实时。
6. 持续运行超过 24 小时，确认时间轴滚动且只显示最近 1440 分钟；慢速读取详情 API 时其他节点活性、接入和 token 撤销仍正常。实际磁盘保留期清理按票 37 另行验收。
