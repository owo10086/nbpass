# 14: 探针资源监控与分钟曲线

**What to build:** 每个节点的探针每 5 秒采样 CPU、内存、磁盘、网卡收发速率、连接数（业务、隧道、系统 TCP 分开）和运行时长，面板显示实时值，并保存分钟聚合（平均值与最大值），提供最近 24 小时曲线；离线期间显示为缺失。

**Blocked by:** 02

**Status:** ready-for-agent

**Refs:** 规格用户故事 108–111；规格「探针存储」「探针采集」

- [ ] 面板显示每个节点的实时指标和在线状态，运行时长从节点进程启动起算
- [ ] 分钟聚合保存平均值与最大值，提供最近 24 小时曲线
- [ ] 离线期间的曲线为缺失而不是零
- [ ] 业务连接数、隧道连接数、系统 TCP 连接数分开显示
- [ ] 指标采集经可注入接口，测试台用替身；真实操作系统指标列入 Linux 人工验收
- [ ] 以上行为由测试台通过面板 HTTP API 验证
- [ ] 节点详情页的实时值与曲线（人工验收）
