# 08: 单成员出口组上的隧道规则

**What to build:** 管理员把一个出口节点放进出口组，创建隧道规则（入口组监听端口 → 出口组 → 目标）。面板为出口生成身份名称稳定的自签证书，入口只信任这张证书；每对入口—出口有独立的隧道凭据，只在 TLS 建立后发送。入口经 WSS + yamux 把流量交给出口，出口解析域名目标并拨号。

**Blocked by:** 03

**Status:** ready-for-agent

**Refs:** 规格用户故事 28、29（隧道部分）、39、40、41、43、51（单出口）；规格「隧道服务端（出口）」

- [ ] 出口证书由面板生成，有效期 5 年，身份名称不随 IP 变化
- [ ] 入口不使用系统根证书、绝不跳过校验；出示错误证书的出口握手失败
- [ ] 入口—出口凭据按对生成、加密存储、只在 TLS 建立后发送；错误凭据被拒
- [ ] 隧道规则的域名目标由出口解析
- [ ] 测试台用真实 TCP 验证：流量经入口 → WSS/yamux → 出口 → 目标到达
- [ ] 唯一出口不可用时新连接失败，不直连目标
- [ ] 出口组、隧道规则编辑界面（人工验收）
