# 24: 活动入口离线时自动切换

**What to build:** 活动入口离线（90 秒）后，面板请国内检测点确认它确实连不上，确认后由协调器切到一个候选成员。没有可用国内检测点时只通知、不切换；没有候选时保留最后的解析、停止切换并通知，不删除记录。切换写入事件日志并发 Telegram 通知，通知失败不阻塞切换。

**Blocked by:** 16, 22, 23

**Status:** ready-for-agent

**Refs:** 规格用户故事 60、61、63、114（切换部分）；必测场景 11；ADR 0005

- [ ] 活动入口控制链路断开且检测点连不上它时，假 DNSPod 记录改为候选成员
- [ ] 面板与该节点断开、但检测点能连上它时不切换
- [ ] 没有可用国内检测点时只通知，不切换
- [ ] 没有候选时记录不变，并通知
- [ ] 假 Telegram 失败不阻塞切换
- [ ] 以上行为由测试台通过面板 HTTP API 与假 DNSPod 验证
