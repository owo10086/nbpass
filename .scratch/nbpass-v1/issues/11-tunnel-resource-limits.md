# 11: 隧道资源上限与清理

**What to build:** 隧道规则同样受节点资源上限约束：每个 yamux 会话的流数量有上限，握手有超时，隧道流正确处理半关闭和取消；达到上限时新连接被拒，控制服务继续响应。

**Blocked by:** 07, 08

**Status:** ready-for-agent

**Refs:** 规格用户故事 132、133；必测场景 17（隧道部分）

- [ ] 每个 yamux 会话最多 1024 个流，超出时新连接被拒（上限可配置，测试用小值验证）
- [ ] 隧道握手有超时，半开握手不长期占用资源
- [ ] 隧道业务连接计入节点和规则的并发上限
- [ ] 隧道流半关闭、取消后资源被回收；达到上限期间控制服务仍响应
- [ ] 以上行为由测试台通过面板 HTTP API 与真实 TCP 验证
