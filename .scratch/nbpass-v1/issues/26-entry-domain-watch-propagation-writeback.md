# 26: 入口组域名解析监控、传播观察与偏差写回

**What to build:** 入口组域名自动加入解析监控，以活动入口为期望值。入口切换后每 30 秒查询，展示"传播中 / 已生效 / 传播未确认"：每条有采样的路径在本期望版本下连续 2 次命中期望值、且其中至少一条国内路径，才记已生效；最长观察时间取"旧记录 TTL × 2"与 10 分钟中的较大者，最多 1 小时。传播观察不阻塞协调器队列，新动作使旧观察失效。DNSPod 上的实际记录与期望不符时由协调器写回；递归解析的差异不触发写回；旧记录 TTL 内的旧值不算污染。

**Blocked by:** 20, 24

**Status:** ready-for-human

**Refs:** 规格用户故事 59（观察值部分）、69（后两个阶段）、99、102、103、105、106；必测场景 1（迟到采样部分）、6；规格「解析监控·生效判定」「入口动作协调器·传播观察不阻塞队列」

- [x] 有人在假 DNSPod 上改了受管记录时，协调器写回
- [x] DNSPod 记录正确但递归解析仍返回旧值时不写回，旧 TTL 内不报污染
- [x] 传播观察期间发生新的故障切换时立即执行，旧观察失效
- [x] 迟到的旧解析采样不会把记录改回旧入口
- [x] 到最长观察时间仍未满足时记"传播未确认"并通知，不标已生效
- [x] 同名残留 AAAA 记录不被修改，也不误报污染
- [x] 以上行为由测试台通过面板 HTTP API、假 DNSPod 与假解析器验证

## Comments

2026-11-09 实施记录（当前 `ticket/26` 分支；仅在指定工作目录实施，沿用现有工作树）：

- **自动纳管与 API**：入口组绑定受管记录时，在同一事务中自动创建解析监控；尚未首次发布时仅观察，发布后以协调器的活动入口 IPv4 和期望版本为准。新增 `GET /api/entry-groups/{id}/dns-watch`，沿用管理员认证；通用解析监控接口返回入口组归属、传播状态、观察截止时间和服务商核对错误。已有同名手工监控自动接管并保留历史；自动监控的期望修改和单独删除返回 409，入口组删除级联清理自身监控。
- **传播阶段与队列**：新动作提交时，在提交期望的同一事务内撤销旧任务、清除旧路径连续证据和观察期限；DNSPod 写入确认后才开始传播观察。动作阶段仍在“服务商已写入”结束并释放协调器队列，传播状态独立持久化为“传播中 / 已生效 / 传播未确认”。传播中每 30 秒查询，结束后恢复每 5 分钟；只有当前有效国内检测点和面板 DoH 路径、当前期望版本的证据参与判定，每条有采样路径连续两次命中且至少一条国内路径才生效。失败或缺轮中断连续命中，不把时间流逝当成功。
- **观察期限与通知**：期限从服务商确认写入的时刻起，取旧记录实际 TTL 的两倍与十分钟的较大者，最多一小时。到期仍未满足就保存“传播未确认”，通过既有解析监控通知待处理表调用 `Panel.RecordEvent` 和 Telegram 异步队列，事件类型为 `entry_propagation_unconfirmed`，同一期望版本只通知一次。终态不会被之后的递归结果改成“已生效”，新动作才开始新的观察。
- **TTL 与记录边界**：保存每次已确认动作的旧 A 值及其独立 TTL 截止，连续切换仍保留更早但尚未过期的缓存宽限；混合的新旧 A 答案也不误计污染。监控仍只采 A，残留 AAAA 不进入期望比对，服务商接口仍只操作绑定的记录 ID。同名其他 A/AAAA 的影响提示沿用既有单线路约定。
- **偏差写回**：新增独立的 DNSPod 核对后台，传播期每 30 秒、平时每 5 分钟读取服务商实际记录；读回偏差才以当时的期望版本提交 `writeback` 动作，由原协调器读回、持久化和写入。递归解析差异没有写入通路。迟到的服务商核对按版本拒绝，迟到采样按任务 ID、轮次和版本拒绝；从旧备份恢复后的暂停保护继续有效。类型、名称、线路等受管边界变化显示待人工核对，外部原始错误不进入 API 或通知。
- **迁移与兼容**：追加 **迁移 29**。重建 `dns_watches` 的唯一性约束，手工域名保持唯一，不同受管记录的同名入口组各有独立监控；迁移前备份并恢复五张子表，保留历史、地址统计、任务和通知及其索引、外键。旧发布按原期望及写入时刻恢复观察，所有已写入动作中尚未过期的旧值仍享受宽限；历史期限已过且无传播证据的旧发布会记“传播未确认”。合并并行迁移时可重排编号。**无需 protobuf 变更，250–259 号段未使用**，沿用票 20 的采样消息与能力。
- **界面**：新增独立 `EntryDomainWatch.tsx`，在入口组详情展示域名、活动入口期望、期望版本、传播进度、观察期限、每条国内/DoH 路径的 A 观察值、状态、连续命中数和最近采样。解析监控列表显示传播阶段与“入口组自动管理”，手工监控继续可编辑。页面状态均来自面板 API。
