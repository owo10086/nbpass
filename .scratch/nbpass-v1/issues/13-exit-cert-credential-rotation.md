# 13: 出口证书与隧道凭据轮换

**What to build:** 管理员可以轮换出口证书和入口—出口隧道凭据。轮换时新旧并存，所有相关入口确认后撤下旧的，最长重叠 7 天；到期仍有入口未确认时保留旧证书并提示，不强行撤下。离线入口重连后收敛。

**Blocked by:** 09

**Status:** ready-for-agent

**Refs:** 规格用户故事 42；必测场景 7（轮换部分）；ADR 0006

- [ ] 轮换期间已有连接和新连接都不中断
- [ ] 部分入口离线时，界面如实显示哪些入口已确认；离线入口重连后收敛，随后撤下旧证书或旧凭据
- [ ] 7 天后仍有入口未确认时保留旧证书并提示
- [ ] 撤下后旧凭据被拒
- [ ] 以上行为由测试台通过面板 HTTP API 与真实 TCP 验证
- [ ] 轮换按钮与确认进度展示（人工验收）
