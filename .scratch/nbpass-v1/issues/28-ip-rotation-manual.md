# 28: 换 IP 接口配置与手动换 IP

**What to build:** 管理员为节点配置自定义换 IP HTTP 接口（URL、方法、请求头、请求体，支持模板变量），并手动触发一次换 IP。面板签发绑定动作 ID、节点、旧 IP 的执行许可（2 分钟有效），作为独立于配置快照的命令下发；节点持有效许可且控制在线时才执行：先用两个查询源查公网 IPv4（失败则取消），再调用接口，之后每 60 秒查一次 IP、最多 5 次，观察到不同的有效公网 IPv4 才算换成。换 IP 凭据只下发给该节点，日志与通知中脱敏。受管记录和出口地址的更新在 30、33 实现。

**Blocked by:** 15, 17

**Status:** ready-for-agent

**Refs:** 规格用户故事 25（IP 变化部分）、83–90、97、98（手动触发部分）；规格「节点模块·换 IP 执行器」「部署形态」（单公网 IPv4）

- [ ] 模板变量 `node_id`、`node_name`、`old_ip`、`action_id`、`timestamp` 在 URL 路径与查询参数、请求头值、JSON 字符串值中按上下文正确编码，请求不经 Shell
- [ ] 带凭据的公网接口必须用 HTTPS 并校验证书；拒绝跨主机重定向和降级到 HTTP 的重定向；HTTP 超时 60 秒，响应上限 64 KB；不继承环境变量中的代理；内网目标需对具体端点显式授权，首次请求和每次重定向都校验实际目标地址
- [ ] 接口返回 2xx 但 IP 未变时不算换成
- [ ] 查询公网 IP 失败时取消，不调用接口
- [ ] 许可过期或节点离线时不执行
- [ ] IP 变化后面板更新节点 IP，并重新识别地区
- [ ] 查询结果为非公网或无效地址时丢弃；检测到 NAT 或多 IP 迹象时，该节点不启用自动换 IP 并提示
- [ ] 测试台的假换 IP 接口能改变节点的模拟公网 IP；以上行为由测试台通过面板 HTTP API 验证
- [ ] 节点换 IP 设置、手动触发按钮与执行进度（人工验收）
