# 28: 换 IP 接口配置与手动换 IP

**What to build:** 管理员为节点配置自定义换 IP HTTP 接口（URL、方法、请求头、请求体，支持模板变量），并手动触发一次换 IP。面板签发绑定动作 ID、节点、旧 IP 的执行许可（2 分钟有效），作为独立于配置快照的命令下发；节点持有效许可且控制在线时才执行：先用两个查询源查公网 IPv4（失败则取消），再调用接口，之后每 60 秒查一次 IP、最多 5 次，观察到不同的有效公网 IPv4 才算换成。换 IP 凭据只下发给该节点，日志与通知中脱敏。受管记录和出口地址的更新在 30、33 实现。

**Blocked by:** 15, 17

**Status:** ready-for-human

**Refs:** 规格用户故事 25（IP 变化部分）、83–90、97、98（手动触发部分）；规格「节点模块·换 IP 执行器」「部署形态」（单公网 IPv4）

- [x] 模板变量 `node_id`、`node_name`、`old_ip`、`action_id`、`timestamp` 在 URL 路径与查询参数、请求头值、JSON 字符串值中按上下文正确编码，请求不经 Shell
- [x] 带凭据的公网接口必须用 HTTPS 并校验证书；拒绝跨主机重定向和降级到 HTTP 的重定向；HTTP 超时 60 秒，响应上限 64 KB；不继承环境变量中的代理；内网目标需对具体端点显式授权，首次请求和每次重定向都校验实际目标地址
- [x] 接口返回 2xx 但 IP 未变时不算换成
- [x] 查询公网 IP 失败时取消，不调用接口
- [x] 许可过期或节点离线时不执行
- [x] IP 变化后面板更新节点 IP，并重新识别地区
- [x] 查询结果为非公网或无效地址时丢弃；检测到 NAT 或多 IP 迹象时，该节点不启用自动换 IP 并提示
- [x] 测试台的假换 IP 接口能改变节点的模拟公网 IP；以上行为由测试台通过面板 HTTP API 验证
- [ ] 节点换 IP 设置、手动触发按钮与执行进度（人工验收）

## Comments

2026-11-09 实施记录（仅当前 `ticket/28` 工作目录；未创建 worktree，未修改 docs/ 或其他票，未推送、合并或切换分支）：

- **接口与秘密**：新增管理员认证和同源保护下的 `GET/PUT /api/nodes/{id}/ip-rotation`、`POST /api/nodes/{id}/ip-rotation/actions`。PUT 接收 `url`、`method`、`headers`、`body`、`private_endpoints`，每次替换完整设置。整个请求模板均通过现有 AES-256-GCM `SecretStore` 保存，普通设置和动作表仅存秘密引用；GET 只返回配置标记、网络风险、最新动作，不回显 URL、请求头或请求体。动作固定引用签发时的设置，后续改设置不改变在途动作。API 入口及序列化后的模板均限制 8 KiB，避免保存后无法下发。秘密只出现在执行节点的独立 TLS 控制消息中，不进入配置快照、其他节点、事件摘要或第三方响应日志。
- **安全请求**：新增 `internal/rotation`。模板写法为 `{{node_id}}`、`{{node_name}}`、`{{old_ip}}`、`{{action_id}}`、`{{timestamp}}`；时间使用 UTC RFC3339Nano。URL 路径按路径段编码、查询值按查询参数编码，请求头变量按百分号编码，JSON 先解析后只替换字符串值再序列化；不解释插入值中的模板标记，不允许主机、JSON 键或请求头名使用变量，不经 Shell。公网接口统一要求 HTTPS（比“携带凭据时才要求”更保守），完整验证证书；禁止跨主机/端口、HTTPS 降级重定向，最多 5 次跳转。内网授权为精确 `scheme://host[:port]/path`，不含查询串，不接受通配符或网段；首次请求、每次重定向及实际拨号均校验解析地址，实际拨已校验的 IP，防止 DNS 重绑定。默认禁止私网、回环、共享地址及特殊 IPv6 范围；显式端点授权只针对该路径生效。HTTP 全程超时 60 秒、响应最多 64 KiB，不继承环境代理，不记录原始错误 URL、请求头、响应体。
- **节点级协调与许可**：面板先事务保存动作 ID、节点、旧 IP、许可期限及授权事件，再通知该节点；同一节点进行中或结果未确认时再次手动触发返回 409。许可有效期 2 分钟，控制连接不在线不签发；节点执行前及落盘开始后再次核对节点绑定、旧 IP、期限和在线状态。命令与完整配置分别发送，不能因动作未确认或命令大小而阻断配置/撤权。接收协程发现断流即撤销在线资格，不等待心跳查询或主循环处理错误。报告身份使用已认证控制会话，迟到动作 ID、旧 IP、旧序号不会覆盖当前动作；不使用第三方拨测驱动动作，符合 ADR 0002、0005、0006。
- **执行与观察**：默认两个查询源为 `api.ipify.org` 与 `ifconfig.me/ip`，每源期限 5 秒。换前必须得到相同的有效公网 IPv4，并与许可旧值一致；失败、非公网、无效或不一致则取消，不调用接口。标准 `FileStore` 自动启用独立加密动作缓存 `rotation.enc`，调用前必须持久化 started；失败绝不调用商家。接口结束后每 60 秒双源查询一次、最多 5 次；只有一致的新公网 IPv4 才记 changed，2xx、HTTP 错误或响应体本身均不证明换成。到期没有确认则为 unconfirmed，不重发接口。调用后断线只继续观察、保存结果，重连独立补报；节点重启恢复 started/observing 的观察，不重新调用。同一动作重复投递只补报已存进度。进度或终态遇临时写盘失败仅重试本地保存，不放弃观察任务、不重调商家。历史最多保留 4096 条，达到容量时原子压缩并保存发行时间水位；含水位边界的旧许可不可执行，避免永久容量卡住和清理后重放。
- **IP、地区与网络风险**：换 IP 动作进行中或结果未确认时，单源活性查询不发布新 IP，防止绕过双源确认。changed 动作、节点公网 IP、自动地区及面板阶段事件在同一事务提交；人工地区覆盖和检测点关闭开关保留。换前比较本机公网 IPv4 集合与双源结果，未发现唯一匹配地址、多个本机公网 IP、查询源不一致均提示 NAT/多 IP 风险，持久标记 `unsafe_network`、返回 `automatic_eligible=false`；本票允许管理员继续手动操作，但不宣称已证明可直接入站。没有自动换 IP 开关或调度器，`automatic_eligible` 只表示后续自动流程的资格接缝。
- **协议与存储编号**：在现有第 7 版之后追加 **迁移 8**，新增 `rotation_settings`、`rotation_actions` 与节点在途动作唯一索引。协议版本仍为 1；`NodeReport.rotation_only=80`、`rotation=81`，`PanelMessage.rotation_command=80`；新 `RotationCommand` 字段使用 **80–86**，`RotationProgress` 使用 **80–87**。已通过 `make proto` 生成 `control.pb.go`，未手改生成文件。节点动作缓存与凭据复用本机密钥、独立关联数据，目录 0700、文件 0600，原子替换和文件/目录同步。自定义凭据 Store 如需换 IP，须实现 `RotationStore` 或显式注入。
- **动作与事件接缝**：进度使用独立 `rotation_only` 报告，只处理匹配动作；不推进活性、探针、事件确认或配置应用，其他报告也不能消费换 IP 结果。面板授权事件与阶段事件沿用票 15 事件表和安全摘要契约，事务阶段使用统一 `insertEvent`；节点开始/变化事件使用 `EventQueue.Record`。只记录固定中文摘要和动作 ID。地区沿用票 17 `RegionLookup`，不使用控制连接地址推断公网 IP。
- **界面**：节点列表新增“换 IP”入口；弹窗提供完整接口设置、敏感字段不回显、手动触发确认、离线禁用、风险提示，以及状态、旧/新 IP、5 次观察进度、许可到期时间和动作 ID。执行中和结果未确认不能重复触发；关闭弹窗或保存后清空填写的凭据。前端每 3 秒刷新进度。
