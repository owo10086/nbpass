# 20: 手动添加域名的只读解析监控

**What to build:** 管理员手动添加任意域名进行解析监控，期望 IP 可选。国内检测点向国内公共 DNS 查询，面板本机用 DoH 查询作对照，解析器列表可配置。每 5 分钟查询一次，记录解析变化历史、变化次数和出现过的不同 IP 数。有期望值时，同一路径对同一期望连续 3 次不符才判异常；疑似污染、解析失败只通知，不触发任何写操作。

**Blocked by:** 16, 17

**Status:** ready-for-agent

**Refs:** 规格用户故事 100、101、102（定时部分）、103、104、106、107、130（解析器部分）

- [ ] 部分路径持续返回非期望地址、其他路径正常时判疑似污染并通知
- [ ] 没有国内检测点时显示"国内覆盖缺失"，DoH 不通时显示"采样失败"
- [ ] 解析器列表可在设置中修改
- [ ] 测试台使用假 DNS 解析器与 DoH；以上行为由测试台通过面板 HTTP API 验证
- [ ] 解析监控页面：变化历史、变化次数、不同 IP 数（人工验收）
