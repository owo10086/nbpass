# 36: 面板命令行升级、备份与从旧备份恢复

**What to build:** 面板命令行升级前先做一致性的在线 SQLite 备份，再执行迁移；迁移失败时 CLI 输出与文档写明恢复范围（程序、数据库、密钥文件），备份附带恢复所需的密钥说明。从旧备份恢复后，自动写操作全部暂停，并清理所有登录会话和安装票据。节点重连时上报配置版本高水位和动作执行记录，面板把新配置版本抬到高于高水位。无法重建最近 24 小时换 IP 尝试记录的节点暂停自动换 IP，直到记录补齐或 24 小时保护窗口过去；无法核对的节点及其入口组继续暂停相关的自动写操作。

**Blocked by:** 22, 30

**Status:** ready-for-agent

**Refs:** 规格用户故事 126、127；必测场景 9（恢复部分）；规格「备份与面板升级 CLI」

- [ ] 测试台用旧数据库快照重建面板：核对完成前不改 DNS、不签发换 IP 许可
- [ ] 恢复后下发的配置版本高于节点高水位，节点接受
- [ ] 恢复前的会话和安装票据失效
- [ ] 节点上报的换 IP 动作记录用于重建额度，不能重建的节点暂停自动换 IP
- [ ] 以上行为由测试台通过面板 HTTP API 验证；CLI 的实际执行列入 Linux 人工验收
