# 23: 就绪与自动切换候选判定

**What to build:** 面板按"节点 × 入口组"计算就绪：本组全部启用规则已应用、监听成功、每条隧道规则至少一个获授权出口握手成功；其他入口组的规则错误不影响本组。自动切换候选除就绪外，还须控制在线、不在维护中、未被墙，并且有未过期（5 分钟内）的国内可达证据，即最近一次正常自测轮或检测点成功；没有证据时标"未知"，不作候选。候选每 10 秒检查一次。

**Blocked by:** 04, 12, 19

**Status:** ready-for-agent

**Refs:** 规格用户故事 22、62；规格「判定汇总·就绪」「自动切换候选」

- [ ] 本组一条规则 bind 失败时，该成员对本组不就绪，对另一个入口组仍就绪
- [ ] 某条隧道规则的所有出口握手都失败时不就绪
- [ ] 被墙、离线、没有国内可达证据的成员不是候选，界面给出原因；"维护中"条件先按模型字段判断，维护功能在 34 实现
- [ ] 以上行为由测试台通过面板 HTTP API 验证
- [ ] 入口组详情显示每个成员的就绪与候选状态及原因（人工验收）
