# 23: 就绪与自动切换候选判定

**What to build:** 面板按"节点 × 入口组"计算就绪：本组全部启用规则已应用、监听成功、每条隧道规则至少一个获授权出口握手成功；其他入口组的规则错误不影响本组。自动切换候选除就绪外，还须控制在线、不在维护中、未被墙，并且有未过期（5 分钟内）的国内可达证据，即最近一次正常自测轮或检测点成功；没有证据时标"未知"，不作候选。候选每 10 秒检查一次。

2026-11-09 实施记录（分支 `ticket/23`；仅操作指定工作目录，未创建工作树、未修改 docs/ 或其他票）：

- **按组就绪**：新增 `entry_readiness.go`，以当前期望快照摘要、逐规则应用版本/错误为依据，只检查本入口组的启用规则；完整节点版本未推进或其他组 bind 失败不会抹去本组的逐规则成功。规则确认涵盖监听成功，停用规则不阻塞就绪。隧道规则逐条使用快照内已授权出口集合匹配当前进程的新鲜成功握手，不能借用同组另一规则的授权；全部握手失败、未完成或样本过期时不就绪。仅为既有零代次单出口快照保留兼容路径，没有健康报告则保守不就绪。
- **候选采样与展示**：沿用 `Dependencies.Clock`，后台每 **10 秒**检查一次，原子替换本轮全部成员状态；`GET /api/entry-groups` 新增有序 `member_states`，包含就绪/候选状态、结构化原因、检查时间和国内证据。HTTP 读取不制造成功样本，启动/重启或采样失败时未知，超过一个周期未更新则失效。入口组展开及“入口组详情”逐成员展示并每十秒刷新，列出具体规则错误、控制离线、维护、被墙及国内证据缺失/过期原因。DNS 绑定和成员编辑均保护未保存内容；新建账号的程序选择也标记为已编辑。
- **国内证据**：新增当前 IP 的持久成功证据，来源为当前配置的有效正常自测轮、有效检测点成功或已绑定新 IP 的正常换 IP 复检。不使用第三方拨测；不把一般心跳、探针或事件当作国内可达证明。按证据发生时间保守计时，**恰好满五分钟即过期**；重复/迟到上报不延长期限，面板重启不刷新证据时间。IP 变化同事务删除证据，覆盖 A→B→A；普通自测还须匹配当前配置版本且在当前地址确认后开始，不能把旧地址或旧配置补报当作新证据。旧历史缺少地址归属，升级时不虚构回填。
- **与票 30 的衔接**：正常新 IP 复检可提供该地址的国内证据；候选计算按发生时间比较最新当前地址正常证据与有效异常证据，避免旧 IP 的被墙状态遮蔽新 IP 恢复，也避免迟到正常覆盖后续异常。该派生判断不改写原始自测状态、轮序、控制活性、配置确认或授权确认，各类 NodeReport 仍独立处理。自动切换和自动回切调度留给后续票。
- **歧义决定**：空入口组的规则条件按空集成立，但仍须通过控制、维护、被墙与国内证据门禁才能成为候选。控制连接一旦中断即排除候选，不把离线事故的 90 秒宽限当成候选在线。维护仅读取 `maintenance_until`；未实现升级/维护流程。正常自测按轮开始时间、检测点按任务签发时间作为保守证据时间，未来时间或已过期补报不采纳；宁可等待下一次成功，也不延长有效期。握手要求最近一次探测成功，探针接收不足十秒且握手时间不足十五秒（最长 5.5 秒探测间隔 + 3 秒握手 + 5 秒上报 + 秒级取整）；`recovering` 的成功握手可证明就绪，出口策略的连续一分钟回切观察仍独立执行。
