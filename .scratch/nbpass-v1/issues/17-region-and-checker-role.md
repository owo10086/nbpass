# 17: 地区识别与国内检测点角色

**What to build:** 面板依据 ip2region 离线库识别节点地区，中国大陆节点默认承担国内检测点角色。管理员可手动覆盖地区或关闭某节点的检测点角色。节点 IP 变化后自动重新识别地区。

**Blocked by:** 02

**Status:** ready-for-agent

**Refs:** 规格用户故事 23、24、25

- [ ] 中国大陆节点自动成为国内检测点，其他地区不是
- [ ] 管理员覆盖的地区优先于自动识别；IP 变化后不被自动结果改写
- [ ] 关闭检测点角色后，该节点不再承担检测点
- [ ] 节点上报的 IP 变化后自动重新识别地区
- [ ] 测试台使用假 ip2region；以上行为由测试台通过面板 HTTP API 验证
- [ ] 节点列表显示地区与检测点角色（人工验收）
