# 07: 直连规则的资源上限与连接清理

**What to build:** 节点对并发业务连接、待拨号数量和每连接缓冲设上限，对拨号和空闲设超时，正确处理 TCP 半关闭和连接取消；达到上限时新连接被拒，但节点仍正常响应控制。

**Blocked by:** 03

**Status:** ready-for-human

**Refs:** 规格用户故事 132、133；必测场景 17（直连部分）；规格「资源限制」与关键参数表

- [x] 每节点 20000、每规则 5000 并发业务连接；超出时新连接被拒，已有连接不受影响（上限可配置，测试用小值验证）
- [x] 待拨号上限 512；拨号有超时；TCP 空闲 2 小时断开；每连接每方向缓冲 32 KB
- [x] 一端半关闭后，另一方向的数据仍能传完
- [x] 连接取消后资源被回收，节点上报的业务连接数归零
- [x] 达到上限期间，面板仍能收到该节点的活性并下发配置
- [x] 以上行为由测试台通过面板 HTTP API 与真实 TCP 验证
