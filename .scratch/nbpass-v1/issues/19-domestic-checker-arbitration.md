# 19: 国内检测点补判

**What to build:** 自测结果未知的轮次，由面板安排国内检测点补判。检测点本轮先连通国内对照站点，结果才算有效；然后对被测节点的固定检测端口发起 TCP 连接，上报原始结果，不检测自己。任一有效检测点连上记正常，全部有效检测点都连不上记异常；零个有效结果、缺报或执行错误都保持未知。补判截止 60 秒，迟到的结果作废。

**Blocked by:** 05, 17, 18

**Status:** ready-for-human

**Refs:** 规格用户故事 73、75、76；必测场景 4、10（冒充上报部分）；规格「判定汇总」「国内检测点执行器」「检测端口」

- [x] 每个节点监听固定检测端口
- [x] 每轮检测任务固定检测点集合、目标 IP 与端口、配置版本；换 IP 后，旧地址的迟到样本作废
- [x] 检测点连不上对照站点时，它的结果无效
- [x] 检测点集合在一轮中变化、缺报或检测点自身网络异常时，补判结果符合三态规则，未知轮中断连续计数
- [x] 节点只能上报分配给自己、仍在有效期内的检测任务结果，不能冒充其他节点
- [x] 以上行为由测试台通过面板 HTTP API 验证
- [ ] 界面标明某轮结果来自检测点补判（人工验收）

- **固定检测监听**：沿用票 05 的 `nodes.check_port` 与端口冲突校验，节点实际监听 IPv4 TCP，默认 18080；完成握手后立即关闭，不承载业务数据。非默认端口进入完整配置快照，变更先持久化撤销检查点再重绑，失败不能确认新配置。实际监听和错误纳入原有加密配置缓存；`CheckConfigured` 区分旧版缺字段与新版明确撤销，防止崩溃恢复旧端口。缺省 protobuf 值兼容默认 18080，不为无关节点伪造额外配置版本；面板打开时补齐旧版已保存的非默认端口快照。节点启动先恢复缓存；旧缓存若有业务/隧道占用默认端口，优先恢复业务，待上线收到已保存的自定义检测端口后再监听，避免离线升级破坏转发。
- **任务与三态**：只对当前开启且配置标识匹配的未知自测轮安排补判，沿用轮 ID、序号和原始结果。任务与原始轮在同一事务保存，固定当时有效大陆地区、未关闭角色、控制在线且不在维护中的检测点集合，排除被测节点自身；固定目标观测 IPv4、检测端口、目标配置版本、对照站点、签发时间与绝对截止时间。任一有效目标连接成功即正常；全部分配点都已报告、至少一项有效且全部有效点失败才异常；无有效结果、缺报或执行错误均保持未知。对照不通的已报告检测点无效，不计作目标失败；存在有效成功时优先正常。零检测点或未知目标地址不伪造失败，立即保留未知。
- **真实执行器与控制隔离**：新增可注入 `CheckerLookup` / `CheckerDial`，生产使用真实 IPv4 解析与 TCP 连接；每任务先解析并连接本轮对照站点 TCP 443，成功才连接固定目标。解析最多 10 秒、每次 TCP 最多 5 秒，受任务总截止约束；保存时间、地址、耗时、成功/失败与执行错误，不传第三方原始响应。EMFILE/ENFILE/ENOBUFS 等本地资源故障属于执行错误，不能补成异常。每条控制流最多八项在途任务，专属结果报告及 ACK，确认期限 15 秒；完成确认释放槽，断流取消未完成执行，重连可重新领取同一未结束任务。任务与结果的面板持久记录可跨面板重启，截止不延长；节点不把补判任务放入自测或事件离线队列。结果不推进活性、地区、探针、事件、换 IP 或配置确认，其他报告也不能消费补判载荷。
- **归属与迟到防护**：以已认证控制流身份核对任务分配，完整核对任务内容与原始证据；消息自带 `node_id` 无法冒充别人。截止以面板接收时间为准，恰好 60 秒起只确认丢弃，不因正常超时完成而断开控制流。原始跨机时间允许五分钟偏差，不延长服务端截止。IP 更新与旧任务失效在同一数据库事务提交，覆盖活性及票 28 换 IP 进度的写入，A→B→A 也不会复活旧任务；目标端口/配置版本变化同样使未结束任务失效。检测点角色中途改变不重新计算本轮集合，缺报不能因移除成员而补成失败。
