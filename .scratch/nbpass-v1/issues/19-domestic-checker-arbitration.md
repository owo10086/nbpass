# 19: 国内检测点补判

**What to build:** 自测结果未知的轮次，由面板安排国内检测点补判。检测点本轮先连通国内对照站点，结果才算有效；然后对被测节点的固定检测端口发起 TCP 连接，上报原始结果，不检测自己。任一有效检测点连上记正常，全部有效检测点都连不上记异常；零个有效结果、缺报或执行错误都保持未知。补判截止 60 秒，迟到的结果作废。

**Blocked by:** 05, 17, 18

**Status:** ready-for-agent

**Refs:** 规格用户故事 73、75、76；必测场景 4、10（冒充上报部分）；规格「判定汇总」「国内检测点执行器」「检测端口」

- [ ] 每个节点监听固定检测端口
- [ ] 每轮检测任务固定检测点集合、目标 IP 与端口、配置版本；换 IP 后，旧地址的迟到样本作废
- [ ] 检测点连不上对照站点时，它的结果无效
- [ ] 检测点集合在一轮中变化、缺报或检测点自身网络异常时，补判结果符合三态规则，未知轮中断连续计数
- [ ] 节点只能上报分配给自己、仍在有效期内的检测任务结果，不能冒充其他节点
- [ ] 以上行为由测试台通过面板 HTTP API 验证
- [ ] 界面标明某轮结果来自检测点补判（人工验收）
