# 06: 登录限流、会话撤销与节点凭据吊销

**What to build:** 连续输错密码的来源被限流，来源 IP 按设置中配置的受信任反向代理解析；修改密码后所有旧会话立即失效；服务器本机可用命令行重置管理员密码；重置或吊销节点 token 时，它已建立的控制流被断开。

**Blocked by:** 02

**Status:** ready-for-agent

**Refs:** 规格用户故事 8、9、11、13、16；必测场景 13

- [ ] 同一来源连续 5 次失败锁定 15 分钟
- [ ] 只有来自受信任代理的转发头才被采信；伪造的转发头既不能绕过限流，也不能把别的来源锁住
- [ ] 修改密码后所有旧会话立即失效
- [ ] 本机命令行可重置管理员密码（实际执行列入 Linux 人工验收）
- [ ] 吊销或重置节点 token 后，已有控制流被断开，旧 token 无法重连
- [ ] 以上行为由测试台通过面板 HTTP API 验证
- [ ] 受信任代理设置界面（人工验收）
