# 06: 登录限流、会话撤销与节点凭据吊销

**What to build:** 连续输错密码的来源被限流，来源 IP 按设置中配置的受信任反向代理解析；修改密码后所有旧会话立即失效；服务器本机可用命令行重置管理员密码；重置或吊销节点 token 时，它已建立的控制流被断开。

**Blocked by:** 02

**Status:** ready-for-human

**Refs:** 规格用户故事 8、9、11、13、16；必测场景 13

- [x] 同一来源连续 5 次失败锁定 15 分钟
- [x] 只有来自受信任代理的转发头才被采信；伪造的转发头既不能绕过限流，也不能把别的来源锁住
- [x] 修改密码后所有旧会话立即失效
- [ ] 本机命令行可重置管理员密码（实际执行列入 Linux 人工验收）
- [x] 吊销或重置节点 token 后，已有控制流被断开，旧 token 无法重连
- [x] 以上行为由测试台通过面板 HTTP API 验证
- [ ] 受信任代理设置界面（人工验收）

## Comments

2026-11-09 实施记录（仅当前 `ticket/06` 工作目录；未修改 docs/ 或其他票）：

- **限流与存储**：新增迁移 **3**，创建 `auth_login_failures` 和 `auth_trusted_proxies`。同一来源第 5 次密码错误即返回 429，锁定 15 分钟；`Retry-After` 返回向上取整的剩余秒数。锁定中的请求不延长截止时间，到期边界立即放行，成功登录清除该来源的连续失败计数。失败、锁定和代理配置均持久化，面板重启不能绕过锁定；密码校验继续共享票 01 的默认 4 并发限制，过载和非法 JSON 不计入密码失败。新增物理测试验证从票 02 的数据库版本 2 升级后保留管理员哈希和节点凭据，且不默认信任任何代理。合并并行票时需协调迁移编号。
- **可信代理 API 与界面**：新增认证及同源保护下的 `GET/PUT /api/settings/trusted-proxies`，请求与响应为 `{"trusted_proxies":["127.0.0.1/32","10.0.0.0/24"]}`；支持 IP/CIDR、IPv4/IPv6，最多 64 项，规范化、去重、事务替换，空列表清空，缺字段或 null 拒绝。仅当 TCP 直连来源受信任才读取 `X-Forwarded-For`；多值头合并，从右向左跳过可信代理，取第一个不可信地址；不能解析的必要链路、带 zone 的地址或实际可信链解析超过 32 跳时回退到直连来源；到达首个不可信地址即停止，左侧超长伪造前缀不改变来源。IPv4 映射地址归一到 IPv4，避免重复失败预算。新增安全设置页，提供代理列表和改密表单，操作结果沿用现有 JSON 错误与会话门禁。
- **改密与并发安全**：新增 `POST /api/auth/password`，请求 `{"current_password":"...","new_password":"..."}`；校验当前密码，新密码沿用 12–72 字节及 bcrypt。密码替换、撤销全部会话和清除失败计数在同一事务中完成，成功返回 204 并清除当前 Cookie。当前密码验证共用来源失败预算和哈希并发上限；提交前重验原会话仍有效、密码哈希未改变，防止已撤销会话或另一轮改密覆盖结果。登录创建会话时也核对当前密码哈希，阻止改密/CLI 重置前开始的旧密码登录在事后创建有效会话。网页改密、CLI 重置均覆盖撤销失败时事务回滚，失败不报告成功。
- **本机 CLI**：新增 `nbpass reset-password -data-dir /var/lib/nbpass`。不启动监听，不要求 public-origin 或面板密钥；要求数据目录已有数据库且管理员已初始化。运行用户必须有数据库目录读写权限。终端输入两遍密码且不回显，非终端标准输入接收两行；拒绝密码参数、无效长度、不一致及缺行，输出不包含密码。通过 `panel.ResetAdministratorPassword(ctx, password, Dependencies)` 复用存储和哈希依赖；可以在面板运行中访问同一个 SQLite 数据库，立即撤销在线面板的所有旧会话并解除登录锁定。新增 `golang.org/x/term v0.47.0` 仅用于终端不回显。
- **节点 token**：沿用票 02 已有的 reset/revoke 管理入口和活动流取消机制，未改节点或控制协议。新增真实节点凭据重放用例，分别吊销/重置后观察 HTTP API 立即显示断开，等待旧凭据的真实重放尝试结束，再确认其不能恢复连接或更新最近活性；票 02 的阻塞回包、等待首报告与新票据重接用例继续通过。
- **TDD 与验证**：先观察到第 5 次失败仍返回 401、代理配置与改密入口 404 等 red，再实现至 green。复核另以回归测试复现超长伪造左前缀导致改算代理 IP、绕过原来源锁定的问题，改为仅计算实际经过的可信跳数后转为 green。新增 12 个测试台顶层场景、1 个 CLI 入口场景和 1 个迁移物理场景，业务结果只经面板 HTTP API 断言；本机 CLI/恢复函数调用、持久化故障注入及节点凭据重放仅作外部环境驱动。覆盖锁定边界/重启/成功清零、超长密码、伪造头、代理链/IPv6/映射地址、非法链回退、认证/同源/非法设置、全部会话撤销、旧密码在途登录、在途登录不能跨越新锁定、在途改密不能跨越会话撤销，以及会话删除失败后的密码回滚。`env -u FORCE_COLOR make test` 全绿（npm ci、TypeScript/Vite、节点包重建、go vet、go test）；`go test -race ./... -count=1` 全绿；新增迁移场景另通过定向普通/race 检查。面板和节点均通过 `CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -trimpath`，`file` 确认为静态链接 x86-64 ELF。Vite 延续 AntD 大于 500 kB 的非阻断提示。
- **歧义决定与范围**：第 5 次错误本身即返回 429；锁定期间即使密码正确也不提前解锁。只采用 X-Forwarded-For，不同时解释 Forwarded/X-Real-IP，避免冲突优先级；代理必须覆盖该头或追加真实直连来源。可信代理默认空列表；IPv4 映射形式的单 IP 会规范化，映射形式 CIDR 要求改填普通 IPv4 CIDR。改密和本机恢复均清除全部来源的失败计数以恢复访问。限流阈值/期限按本票验收固定为 5 次/15 分钟，统一可调参数设置未在本票扩展。无其他规格行为偏离，无阻塞实施的开放问题。
- **构建产物与后续接缝**：本票依赖**重新生成前端产物**才能在内嵌页面显示安全设置；不依赖重新生成节点二进制或控制协议。提交前按要求执行 `git checkout -- web/dist internal/nodebundle`，并删除本次前端构建新增的未跟踪资源，仅提交源码。后续 CLI 票可沿用现有子命令分派与本机恢复入口；认证/代理设置沿用 `panel.Open` 和 `Dependencies`，未为其他业务增加诊断 API 或新认证方式。
