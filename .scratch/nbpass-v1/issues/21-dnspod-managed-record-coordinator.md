# 21: DNSPod 受管记录绑定与入口动作协调器

**What to build:** 管理员为入口组绑定域名和一条 DNSPod 受管记录，记录唯一绑定账号、域名、记录 ID 和线路，DNSPod 凭据加密存储。绑定时面板读回并展示当前记录值，拒绝非 A 记录和多线路，提示同名其他 A/AAAA 记录可能造成的影响。首次发布须由管理员显式确定活动入口，经入口动作协调器写入。协调器为每个入口组维护一个串行队列：外部动作先持久化动作 ID、旧值、新值再执行，分阶段记录"期望已变更 / 服务商已写入"；写入超时记"结果未确认"，先读回核对再决定；面板重启后先核对 DNSPod 上的实际记录，再继续未完成的动作。DNS 服务商接口抽象为"读取记录 / 写入记录"，v1 实现 DNSPod。

**Blocked by:** 03

**Status:** ready-for-agent

**Refs:** 规格用户故事 55、56、57、67、68、69（前两个阶段）、131（DNSPod 部分）；必测场景 1（写入部分）；规格「入口动作协调器」「DNS 服务商接口」；ADR 0005

- [ ] 同一 DNSPod 记录只能归属一个入口组，重复绑定被拒
- [ ] 非 A 记录、多线路被拒；同名存在其他 A/AAAA 记录时给出提示，不删除
- [ ] 首次发布后，假 DNSPod 上的记录值为活动入口 IP，TTL 60 秒；其他记录不变
- [ ] DNSPod 写入成功但响应丢失时，动作为结果未确认，读回核对后完成，不重复写
- [ ] 动作持久化失败时不调用 DNSPod（测试台增加持久化故障注入）
- [ ] 面板在写入中途重建后，先读回核对再续做
- [ ] DNSPod 凭据不回显，日志脱敏
- [ ] 以上行为由测试台通过面板 HTTP API 与假 DNSPod 验证
- [ ] 绑定与首次发布界面（人工验收）
