# 18: 自测与被墙认定

**What to build:** 每个节点可单独开启自测：每 2 分钟一轮（带抖动），TCP 连接 4 个可配置国内站点的 443 端口，至少 3 个连不上为异常轮，任一站点解析失败为未知轮。连续 3 个异常轮认定被墙；未知轮中断连续计数；正常轮清零计数，并解除疑似被墙和被墙。界面显示每轮的原始结果、时间和证据来源，被墙与解除写入事件日志并发 Telegram 通知。本票只做自测，检测点补判在 19 实现，在此之前未知轮保持未知。

## Comments

2026-11-09 实施记录（分支 `ticket/18`，仅在当前工作目录内读写；规则文件只读；未修改 docs/ 或其他票）：

- **节点自测**：新增 `internal/selfcheck` 配置/证据模型和 `node.selfCheckRunner`。每节点默认关闭；开启即执行首轮，此后以轮开始时间为基准，每 120 秒加减最多 12 秒抖动。抖动由节点身份与轮次散列，重启仍稳定且各节点错峰。调度迟到不伪造补采轮次。四个域名有限并行解析 IPv4，每站点最多两次解析、每次默认 10 秒；取最多两个不同 IPv4，依次 TCP 连接固定 443 端口，每次默认 5 秒，任一地址成功即该站点正常。单轮共享默认 60 秒期限；未完成与解析失败均为未知，不能补成 TCP 失败。
- **判定与证据**：至少三个站点 TCP 失败为异常；任一站点未知则整轮未知。连续第一、第二个异常轮为疑似被墙，第三个异常轮认定被墙；未知轮清零连续计数，保留既有疑似/被墙状态；一个正常轮清零并解除。原始轮结果、开始/结束时间、站点、解析次数/地址、逐地址连接结果/耗时、配置版本和 `self_check` 来源保存并可查询。原始 `result` 与 `final_result`、`evidence_source` 分列；本票未知轮保持未知，不派检测点任务、不驱动换 IP、DNS 或入口动作。
- **配置接缝**：`GET/PUT /api/settings/self-check` 管理全局四站点及参数，`GET/PUT /api/nodes/{id}/self-check` 管理节点开关和读取判定/历史。历史默认 100 条，支持 `limit`（1–1000）与 `before` 游标。沿用管理员认证、同源、严格 JSON 和完整快照事务编译，未变化配置不增 revision。参数允许缩短超时用于环境适配，但连接不超过 5 秒、解析不超过 10 秒且最多两次、单轮不超过 60 秒；周期 30–3600 秒，抖动 0–30 秒且小于周期一半。自测 `ConfigKey` 只覆盖自测设置，其他转发/隧道快照版本变化不改变检测周期或中断计数。旧自测设置的结果保留历史，但不推进当前判定。关闭开关保留历史状态，不把关闭当作恢复。
- **离线与持久化**：新增独立 `SelfCheckStore`，标准 `FileStore` 自动使用 `self-check.enc` 加密保存配置、序号、下轮时间和未确认结果；节点重启先恢复该配置并启动自测，再建立控制流。控制断开不会停掉检测。文件沿用本机密钥与独立 AES-GCM 关联数据，目录 0700、文件 0600、原子替换和文件/目录同步，拒绝损坏密文、不安全权限及符号链接；缓存有 64 MiB 物理大小上限，不静默淘汰结果。结果先落盘再发送，确认也先落盘再消费；保存失败保留原状态，进程内重试同一已完成轮，不重做该轮网络请求。自定义凭据 Store 要启用此能力须实现或注入 `SelfCheckStore`。自测结果使用独立队列，不套用事件队列的 24 小时补报期限。
- **控制流隔离**：自测每批最多 8 轮/48 KiB，单独 ACK 和 15 秒确认期限；缺确认时重连重传，不由其他回包消费。接收身份取认证控制会话，按节点/轮 ID 与持久序号去重，旧流与旧进程实例沿用已有保护。自测报告不推进活性、探针、事件确认、换 IP 进度或配置应用；活性、探针、事件、换 IP 与配置确认也不消费自测载荷。连续补报仍让出到期心跳与最新探针。
- **事件与通知**：被墙和解除（含疑似解除）使用 `node_blocked`、`node_unblocked`。状态/历史与通知待办在一个事务提交，提交后通过 `Panel.RecordEvent`、`Panel.QueueTelegram` 写日志和通知；稳定 ID 去重，后台恢复未完成待办，事件写失败不提前确认轮次。通知只提交安全中文摘要和节点名称，不等待 Telegram 网络请求。正常到正常、被墙到持续异常均不重复通知；离线补报保留原始发生时间。
- **界面**：节点页增加“自测设置”与“自测与被墙认定”。可设置节点开关、全局站点和参数；详情每五秒刷新，显示状态、连续计数、每轮时间/原始和最终结果/证据来源/配置版本，展开逐站点原始证据，支持加载较早轮次且刷新保留已加载页。界面明确自测为出站推定，不宣称已证明全国入站可达。事件页增加两种事件的中文标签。
