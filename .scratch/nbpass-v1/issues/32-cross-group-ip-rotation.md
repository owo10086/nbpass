# 32: 跨入口组的换 IP

**What to build:** 一个节点属于多个入口组时，只要该节点开启了自动换 IP，任一入口组（策略①或③）需要就执行；"仅入口切换"只表示本组不申请换 IP、不拦截其他组。换 IP 按节点串行，执行前有就绪候选的相关入口组先完成切离，没有候选的组按各自的退化或保留规则处理，并在事件中记录影响。完成后各组按当时的活动入口与期望版本更新记录，而不是一律改回该节点。

**Blocked by:** 31

**Status:** ready-for-human

**Refs:** 规格用户故事 95；必测场景 5；规格「入口动作协调器·跨组换 IP」

- [x] HK1 同属 A（策略③）和 B（策略②）：HK1 被墙后，B 切离、A 切到备用，再给 HK1 换 IP，换完后各组按自己的回切规则处理
- [x] 节点关闭自动换 IP 时，任何组都不触发换 IP
- [x] 两个组同时申请时只执行一次，额度共用
- [x] 全部入口都被墙时不发生无限动作
- [x] 已切离且不回切的组，不被改回该节点
- [x] 以上行为由测试台通过面板 HTTP API、假换 IP 接口与假 DNSPod 验证
