# 07: 追踪 DNS 异常与传播结果

**What to build:** 管理员能从首页或解析监控定位 DNS 传播未确认、解析期望不符及疑似污染的故障，查看各路径的证据和当前期望。与既有入口动作有明确关系的传播过程进入原故障，独立 DNS 异常保留自己的故障记录，不被错误归因到节点。

- [x] 迟到旧版本采样不覆盖新状态；更换绑定、删除监控或新的期望替代原流程时标明相应结束方式。疑似污染的展示不会触发新的入口切换或换 IP。
