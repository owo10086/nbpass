# 02 端口管理页（原转发规则）

Status: resolved
Blocked by: 01

把 `Rules.tsx`（及 `RulesTransfer.tsx`、`ListOrder.tsx` 中相关部分）改成原型 `pages/ports.js` + `pages/port-parts.js` 的样子，路由 `#/ports`。

- 列表列照原型取现有能映射的：ID、名称、线路（入口节点/入口组）、服务端口、目标、转发模式（直连 / 单跳转发，单跳显示端点组）、状态、流量、连接、操作。没有的（入站协议标签、TOT、链式等）不显示。
- 筛选卡片：名称/目标搜索、线路、模式、状态 + 刷新，要真的能过滤。
- 页头操作：添加端口转发（主按钮）、批量相关、导入/导出等现有能力。
- 行操作：编辑、暂停/启用、复制（若现有支持）、删除等现有能力；其他放「更多」。
- 表单：弹窗，区块化（基本信息 / 转发配置），转发模式用分段按钮「直连 / 单跳转发」；只放后端已有字段。
- 页面文案统一新叫法（端口、服务器、服务器组、端点组、线路）。
- 页面专属样式放独立 CSS 文件；复用 01 的积木，不改共用积木（确需改动在交付说明里写明）。不重建 `web/dist`。

## Comments

### 交付内容

- 端口页复用 `PageHeader`、`FilterCard` / `FilterField`、`TableCard`、`StatusDot`、`ColorTag`、`FormSection`，页面专属样式集中在 `web/src/Rules.css`。
- 表格按原型顺序展示 ID、名称、线路、服务端口、目标、转发模式、状态、流量、连接和操作；保留额外的同步状态列，支持原有同步状态排序。单跳转发显示对应端点组。
- 名称 / 目标搜索、线路、模式、状态筛选均作用于真实列表，可组合使用、清空或一键重置。筛选回到第一页；跨页及筛选外选择继续保留，并在已选提示中明确说明。
- 新增 / 编辑弹窗分为「基本信息」「转发配置」，线路用分组下拉统一选择服务器或服务器组，转发模式用「直连 / 单跳转发」分段按钮。保留自动分配服务端口、目标端口、私网目标开关和启用开关。
- `RulesData.ts` 负责筛选及表单到现有 API 字段的转换，不更改接口；自动分配继续同时提交 `listen_port: 0` 和 `random_port: true`。本页新增的成员详情组件沿用现有同步数据，并使用服务器等新名称。

### 与原型的有意差异

- 只提供后端现有的 TCP 转发、单个 IPv4 / 域名目标、直连和经端点组的单跳转发。目标地址与目标端口分开填写；自动分配端口由显式开关控制。
- 不展示多目标、入站代理、UDP、链式 / TOT、Fallback、带宽 / 配额、测速 / 延迟诊断、网络规划等演示字段与操作；现有页面无复制端口能力，因此不新增复制操作。
- 状态显示「已启用 / 已暂停」，分别呈现配置开关与同步状态，不将已启用误称为已实际运行。同步状态保留独立列及成员展开详情，避免丢失原有排查和排序能力。
- ID 沿用后端真实字符串，列表显示前 8 位；悬停查看完整值，也可复制完整 ID。使用 AntD 的真实分页，每页可选 20 / 50 / 100 条。
- 不添加原型中的假按钮；页头保留现有导入 / 导出和批量操作。

### 现有功能的位置

- 导入 JSON、导出全部 / 所选：页头按钮。导入弹窗保留格式 1 / 2、新增 / 按 ID 覆盖、文件上传 / 粘贴、整体预检、逐项错误及冲突数量、整批确认写入。
- 批量启用、暂停、删除：勾选后使用页头「批量操作」菜单；批量暂停 / 删除保留连接中断确认。取消选择在表格上方。
- 编辑、暂停 / 启用：表格行操作。删除：行「更多 → 删除端口」，保留确认。
- 成员服务器的控制连接、服务端口、期望 / 实际生效版本、同步状态和应用错误：展开行，或行「更多 → 查看成员生效版本」。带 `focus` 的关联链接自动展开，页内可返回全部端口。
- 列排序仍在各列表头；「恢复自定义顺序」在排序后的表格上方。无筛选 / 定位 / 列排序时，左侧手柄仍可拖动并保存全集顺序；拖动期间暂停定时刷新。
- 自动分配端口在新增弹窗「基本信息」；私网目标与启用开关在「转发配置」。自动刷新仍为每 5 秒，手动刷新在筛选卡片。
