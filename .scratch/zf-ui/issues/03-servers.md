# 03 服务器管理页（原节点）

Status: resolved
Blocked by: 01

把 `Nodes.tsx` 及节点子组件（`NodeMetrics`、`NodeRegion`、`NodeUpgrade`、`NodeSelfCheck`、`NodeRotation`、`NodeManagedRecord`、`NodeValidationActions`、`ProbeDetails` 等）改成原型 `pages/servers.js` 服务器列表的样子，路由 `#/servers`。

- 列照原型取能映射的：ID、名称/入口地址、状态、所属服务器组、CPU/内存、端口数、流量、版本、操作。没有的（网卡/端口区间、续费等）不显示。
- 筛选：名称/地址搜索、状态、服务器组 + 刷新。
- 页头：添加服务器（主按钮，沿用现有新增节点 + 安装票据流程，安装命令弹窗做成原型「安装脚本」样式）。
- 行操作：编辑、安装脚本、升级、维护、自检、换 IP、受管记录、删除等现有能力，次要的进「更多」或详情抽屉。
- 文案统一新叫法。页面专属样式放独立 CSS；复用 01 积木；不重建 `web/dist`。

## Comments

### 交付内容

- 服务器列表采用页头、筛选卡片、表格卡片布局，复用 `PageHeader`、`FilterCard` / `FilterField`、`TableCard`、`StatusDot`、`ColorTag`、`FormSection`。支持名称 / 上报 IP / 确认 IP / 受管域名搜索、状态、服务器组及未分组筛选、刷新、右下角分页。
- 列表展示真实服务器 ID（缩写，详情可复制完整值）、名称与入口地址、状态、全部所属服务器组、CPU / 内存、启用业务端口数、实测上下行网络速率、版本和行操作。服务器组与端口数通过现有 `/entry-groups`、`/rules` 接口映射，不改 API。
- 新增 `NodeInstallation`、`NodeServerDetails`、`NodeServerData` 与页面独立 `servers.css`。编辑器、安装脚本及运维弹窗统一深色主题、表单分区和服务器文案；窄屏筛选竖排，解除表格固定列，保留横向滚动。
- 保留每 10 秒刷新、勾选与批量维护、拖动自定义顺序、列排序及恢复自定义顺序。内存、业务连接数、地区、最近活性的排序入口放在表格工具区「更多排序」。通知 `focus` 定位会清除筛选与排序并跳到目标所在页。

### 与原型的有意差异

- 不显示后端没有的共享邀请、续费、网卡名称、端口区间、限速 / 配额、协议权限、额外入站地址、默认转发 / Fallback、演示重启或同步按钮。
- 地址由服务器自动上报，编辑器仅修改显示名称，地区与检测点、预留监听端口分别保存；受管地址由现有确认 / 同步流程管理。
- 服务器可同时属于多个服务器组，因此显示全部成员关系。端口数为本机及所属组中已启用的业务监听端口去重数，不包含隧道 / 检测预留端口，也不冒充实际应用成功的数量。
- 后端没有服务器累计流量 / 流量配额接口，列表使用有明确名称与提示的「网络速率」，不把规则累计流量叠加为服务器流量。CPU / 内存保留原有绿 / 橙 / 红阈值和明细提示。
- 安装脚本使用现有 Linux amd64 安装命令与一次性 30 分钟票据，不提供无后端支持的架构 / 网卡选项。打开已有服务器的安装弹窗只读；点击生成 / 重新生成并确认后才重置凭据，明确告知断开控制连接、旧凭据与票据失效。票据不写入浏览器存储。
