### 与原型的有意差异汇总

| 范围 | 保留的实际行为 / 不展示的原型能力 |
|---|---|
| 导航与占位 | 使用 nbpass 品牌与现有业务分组；转发链、智能 DNS、延迟监控总览仅规划中。无共享服务器、WireGuard、NAT 穿透、路由配置、订阅、商城或演示卡片墙。 |
| 端口 | 仅现有 TCP、单个 IPv4 / 域名目标、直连或经端点组单跳；地址和端口分开填写，自动分配显式开关。无 UDP、多目标、代理入站、TOT / 链式 / Fallback、带宽 / 配额、测速或现有 API 不支持的复制操作。启停状态与配置同步证据分别展示，不将“启用”当作业务已运行。 |
| 服务器 | 可同时属于多个组；端口数按已启用期望配置去重，网络速率来自探针，不伪造累计流量 / 配额。安装脚本仅 Linux amd64、一次性 30 分钟票据，重发凭据须确认。无共享邀请、续费、网卡选择、端口区间、权限或演示重启按钮。 |
| 转发端点 | 沿用服务器名称，一台服务器一个端点；仅 IPv4 + WSS；保留证书、凭据轮换、被墙处理和按入口采样的真实链路健康。无独立名称、域名 / IPv6 / 多协议开关、共享 / 导入、独立删除、启停、配额 / 流量 / 延迟测试。控制在线不等于链路健康，过期观测显示历史证据。 |
| 端点组 | 仅已有主备有序成员策略；成员用序号、单项 / 批量上下移排序，未新增原型的拖拽、序号跳转、Shift 多选、双击添加、描述或自动添加。 |
| 服务器组 | 发布模式建组时选定，之后不可改；成员顺序上下移，不提供端口区间、描述、自动加入模板、入站策略、互测阈值或脚本链接。DNS 列显示真实发布阶段，不添加后端不支持的开关。 |
| DNS 与运维 | 组创建后另行绑定 / 首次发布；TTL 沿用 60 秒。主备 A / CNAME、全部发布 A；CNAME 必须指向活动服务器可确认的受管记录。解绑、更换与删除不删除远端记录；全部发布、观测、回切及换 IP 保留现有约束。 |
| 监控、设置与交互 | 概览以真实证据和处理进度为中心；保留监控筛选、历史加载、事件缺口与设置能力，仅显示有来源的真实数据。保留导入导出、批量操作、排序、复制完整 ID、真实分页和运维弹窗。 |
