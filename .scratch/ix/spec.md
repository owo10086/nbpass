# IX / 专线中转：专线地址、端口映射、转发链与出站 IP

Status: ready-for-agent

参考：Zero Forwarder「IX 使用说明」https://www.zeroforwarder.com/docs/ix-guide/ （以及 /docs/jp-us-lan/、/docs/fwd-chain/、/docs/config/），Forwardx 的「主机入口地址 / 内网地址 + 按主机顺序建隧道」模型。决策记录见 `docs/adr/0009-ix-addresses-and-chains.md`。界面名称见 `GLOSSARY.md`（服务器 = 节点，转发端点 = 隧道出口，端点组 = 出口组，端口 = 规则）。

## 背景

IX / 专线场景：客户端 → 入口服务器 A →（专线 / 内网）→ 中转服务器 B →（可再经 C…）→ 目标。A、B 都能直接连面板，只有业务需要走专线。

现状（2026-11-12 只读调研）：A 已经能用管理员手填的 IPv4 内网地址经单跳转发连到 B（证书按内部名称校验，不受 IP 影响）。缺口：
- 一台服务器只有一个端点地址，所有入口共用；不能同时有「公网」和「专线」地址。
- B 换公网 IP（含手动换）会把手填的专线地址覆盖成新公网 IP。
- A 连的端口就是 B 本机监听端口，不能表达 NAT / 专线端口映射。
- 端点地址不能填域名。
- 没有多跳（A→B→C）。
- B 连目标时不能指定出站源 IP。

## 已定决策（2026-11-12 用户确认）

1. **模型按 Forwardx 思路**：地址挂在服务器上，路径按顺序选。不做 Zero Forwarder 的智能选择、固定前/后 N 跳、服务器级「使用转发端点作为传输」开关。
2. **服务器的端点地址**：
   - 「公网地址」：即现有端点地址，换 IP 时照旧自动更新。
   - 「专线地址」：可加多条，每条 = 名称（如「沪日 IX」）+ IPv4 或域名 + 对外端口（可空）。换 IP 永不改动专线地址。
   - 每个地址的「对外端口」留空 = 本机监听端口；填了即表示前一跳连这个端口，由运营商 / NAT 映射到本机监听端口（支持端口映射）。公网地址同样可填对外端口。
   - 域名由前一跳服务器解析，只用 IPv4。本次不做 IPv6、不做监听绑定 IP（仍监听全部 IPv4 地址）。
3. **端点组成员 = 服务器 + 用它的哪个地址**（公网或某条专线）。同一组里一台服务器只出现一次。现有成员迁移为「公网地址」，行为不变。
4. **转发链**：
   - 在「转发链管理」页保存：名称 + 按顺序排列的端点组（至少 2 跳）。可被多条端口复用；改链 = 所有引用它的端口一起改。
   - 端口转发模式变为：直连 / 单跳转发（选一个端点组，即一跳的链）/ 链式转发（选一条链）。
   - 路径：入口 → 第 1 组的一个成员 → 第 2 组的一个成员 → … → 目标。每台服务器只负责连下一跳：对下一跳组按主备顺序选健康成员、做健康检查和故障切换（沿用现有单跳的主备语义）。
   - 校验：同一台服务器在一条完整路径（入口 + 各跳所有成员）里不能出现两次；被端口引用的链不能删除；引用的端点组不能删除。
   - 每一跳只接受来自上一跳的连接、只连下一跳或该端口授权的最终目标（沿用现有逐对认证与目标授权）。
5. **出站源 IP**：服务器可选设置「出站 IP」（IPv4）。该服务器连接最终目标时（直连端口的入口、单跳 / 链的最后一跳）绑定此源地址；连接下一跳不绑定。不填 = 按系统路由（现状）。节点发现该地址不是本机地址时报应用错误，不静默回退。
6. **不做**：管理连接经中转（A、B 都能直连面板）、无法联网机器（Halo IX）的安装、UDP（下一个独立功能）、IPv6、智能选择 / 固定跳数、服务器级默认传输、监听绑定 IP。

## 界面

- 转发端点页：每个端点显示公网地址和专线地址列表；编辑可增删专线地址、填对外端口。
- 端点组：添加成员时选「服务器 · 地址」（如「B · 公网」「B · 沪日 IX」）。
- 转发链管理（替换「规划中」占位页）：列表（名称、路径预览、引用端口数、各跳健康）+ 新建 / 编辑（名称、按顺序添加端点组、上下移）。
- 端口：转发模式三选一，「链式转发」时选链；端口列表与详情显示完整路径。
- 服务器编辑：「出站 IP」可选字段，带说明。
- 沿用 zf-ui 的界面规范（DESIGN.md）。

## 兼容与升级

- 迁移后现有端口、端点组的行为不变。
- 链、专线地址、对外端口、出站 IP 需要新版节点。面板不得把新配置下发给不支持的旧版节点：对应端口同步状态显示「需升级服务器」类提示，不影响该节点上的其他端口。
- 遵守 ADR 0006 的配置版本与离线授权。

## 验收

- `npm --prefix web run build`、前端测试、`GOFLAGS=-timeout=30m make test` 通过。
- 集成测试（clusterharness）覆盖：A→B（专线地址 + 对外端口映射）→目标；A→B→C→目标；链中某跳主备切换；B 换公网 IP 后专线地址不变；出站 IP 生效与非本机地址报错；旧版节点不收到新配置。
- 本机 http 回环面板逐页检查新界面（编排者做浏览器验收）。
